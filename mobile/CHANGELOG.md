# 햄찌법원 앱 (Capacitor) 변경 기록

버전은 `mobile/app-version.json` 한 곳에서 관리한다 (`pnpm app:bump`). versionCode는 다시 쓰지 않는다.
웹(Vercel) 배포는 이 앱에 들어가지 않는다 — 앱 화면·판독 규칙·예시가 바뀌면 앱을 다시 빌드해 올린다.

## 다음 버전 (아직 버전을 올리지 않음) — 2026-11-20
- 화면 전면 개편: 아테네 신전풍 디자인(대리석·남색·금박·그리스 문양), 시작 화면, 아래 탭 다섯 (DEC-049)
- 온라인 기능: AI 답변(답변 단계·DeepSearch), 판례·법령 탐색, 광장(커뮤니티), 남은 질문·씨앗 — 웹과 같은 API
- 서버에 닿지 않을 때: 규칙 판독·검증된 예시·기기 안 서고(조문·판례 목록)로 동작
- 절차와 서식(분야 40개 절차 순서, 공식 서식 14종 안내), 햄찌 안내, 글자 크기 설정
- 기기에서 확인할 것: CapacitorHttp로 배포 사이트 API에 닿는지, 익명 세션 쿠키가 유지되는지

## 1.1.0 (versionCode 2) — 2026-11-20
- TWA(웹 화면을 띄우는 방식)에서 Capacitor 앱으로 바꿈 (DEC-048)
- 인터넷 없이 쓰는 규칙 판독기: 절차 섹션·입장·확인할 사실·절차 순서·비슷한 예시
- 검증된 예시 답변 45건을 앱에 넣음 (인터넷 없이 열람)
- 온라인 AI 판독은 자리만 두고 꺼 둠
