# lib/pii — PII 필터 (F-007)
탐지·마스킹. 원문은 요청 메모리에서만 처리하고 저장·로그 금지 (DEC-006).

- `scanInput(raw)` → `{ maskedText, findings(유형·개수), sensitive(범주) }`. 일치한 값은 반환하지 않는다.
- 마스킹: 주민번호·전화·이메일·계좌/카드·주소(도로명·지번·동호수)·이름. 이름은 호칭(씨·님 등), 관계어(집주인·친구 등), "이름은 …" 문맥으로 찾고, 같은 사람은 같은 번호(`[이름1]`)로 가린다. 성씨 글자로 시작해도 동사 활용형('구해야'·'고소하려면')·띄어 쓴 조사('한테서'·'하고')·사건 낱말('정규직'·'임금체불')·가족·관계 낱말('전처'·'장모님'·'남자친구', `전`·`님`·`분`을 붙인 꼴 포함)은 이름으로 보지 않는다(`looksLikeVerb`·`isParticle`·`NOT_NAMES`·`KINSHIP`). 한 글자 호칭 `군`·`양`은 뒤에 조사가 오거나 낱말이 끝날 때만 본다('양육비'의 '양' 제외).
- 민감정보(F-007 AC2): 건강·범죄경력 단어 → 저장 전 별도 동의.
- 재현율 우선. 문맥 없는 이름은 놓칠 수 있어, 사용자가 마스킹본을 확인·수정하는 단계(pii-confirmation)를 둔다.
