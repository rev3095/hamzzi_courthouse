# lib/pii — PII 필터 (F-007)
탐지·마스킹. 원문은 요청 메모리에서만 처리하고 저장·로그 금지 (DEC-006).

- `scanInput(raw)` → `{ maskedText, findings(유형·개수), sensitive(범주) }`. 일치한 값은 반환하지 않는다.
- 마스킹: 주민번호·전화·이메일·계좌/카드·주소(도로명·지번·동호수)·이름. 이름은 호칭(씨·님 등), 관계어(집주인·친구 등), "이름은 …" 문맥으로 찾고, 같은 사람은 같은 번호(`[이름1]`)로 가린다. 성씨 글자로 시작해도 동사 활용형('구해야'·'고소하려면')·띄어 쓴 조사('한테서'·'하고')·사건 낱말('정규직'·'임금체불')·가족·관계 낱말('전처'·'장모님'·'남자친구', `님`·`분`과 `전(前)`을 붙인 꼴 포함)은 이름으로 보지 않는다(`looksLikeVerb`·`isParticle`·`NOT_NAMES`·`KINSHIP`). 가족·일반 낱말은 꼬리가 받침과 맞는 조사일 때만 빼서('전처가'는 빼고 '이모은'·'이하은'은 이름) 재현율을 지킨다(`particleFits`). 호칭 앞말이 낱말 + 조사로 나뉘면('남편이 양다리', '나는 사장님한테') 이름으로 보지 않는다(`isWordWithParticle`). 가족 낱말은 늘 나누고('남편이 군 복무', '남친이 사장님한테'), 일반 낱말은 호칭과 상관없이 이름 끝 글자(은·이·아·야·랑·도·로)로 나누지 않는다('이웃은 사장님'·'이사야 씨'는 이름). 이름 앞부분이 되기 어려운 때·부사·기관 낱말(`ALWAYS_SPLIT`: 지금·오늘·정부·고객 등)만 늘 나눈다('지금은 사장님이', '오늘도 사장님이'). 한 글자 호칭 `군`·`양`은 그 글자로 시작하는 낱말('양육비'·'군대') 앞에서는 앞말이 3글자 이상 이름일 때만 가린다.
- 민감정보(F-007 AC2): 건강·범죄경력 단어 → 저장 전 별도 동의.
- 재현율 우선. 문맥 없는 이름은 놓칠 수 있어, 사용자가 마스킹본을 확인·수정하는 단계(pii-confirmation)를 둔다.
