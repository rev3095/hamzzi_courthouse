# lib/pii — PII 필터 (F-007)
탐지·마스킹. 원문은 요청 메모리에서만 처리하고 저장·로그 금지 (DEC-006).

- `scanInput(raw)` → `{ maskedText, findings(유형·개수), sensitive(범주) }`. 일치한 값은 반환하지 않는다.
- 마스킹: 주민번호·전화·이메일·계좌/카드·주소(도로명·지번·동호수)·이름. 이름은 호칭(씨·님 등), 관계어(집주인·친구 등), "이름은 …" 문맥으로 찾고, 같은 사람은 같은 번호(`[이름1]`)로 가린다.
- 민감정보(F-007 AC2): 건강·범죄경력 단어 → 저장 전 별도 동의.
- 재현율 우선. 문맥 없는 이름은 놓칠 수 있어, 사용자가 마스킹본을 확인·수정하는 단계(pii-confirmation)를 둔다.
