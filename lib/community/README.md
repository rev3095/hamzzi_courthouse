# lib/community — 커뮤니티와 씨앗 (DEC-047)

법·제도 의견, 가정해 보는 질문, 잡담처럼 절차 안내가 맞지 않는 이야기를 나누는 게시판. AI를 부르지 않는다.

| 파일          | 역할                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `policy.ts`   | 순수 규칙: 게시판 목록 `BOARDS`, 길이 제한 `LIMITS`, 입력 검사, 수정·삭제 권한 `canChange`, 화면용 모양, 씨앗 숫자 `SEEDS`       |
| `password.ts` | 비로그인 글 비밀번호 scrypt 해시·확인. 평문은 저장·로그·응답 어디에도 남기지 않는다                                              |
| `store.ts`    | server-only. `community_posts`·`community_comments`·`seed_ledger` 읽기·쓰기, DB 함수 `award_seeds`·`revoke_seeds`·`seed_summary` |
| `service.ts`  | server-only. 라우트가 부르는 흐름: 레이트 리밋 → 입력 검사 → `scanInput` 마스킹 → 저장 → 씨앗 적립·회수                          |

## 규칙

- **누구나 쓴다**: 비로그인은 글·댓글마다 비밀번호를 정하고 그 비밀번호로 수정·삭제한다. 로그인하면 비밀번호 없이 쓰고 그 계정으로만 수정·삭제한다. 관리자 모드는 지울 수만 있다.
- **개인정보**: 제목·본문·댓글은 마스킹본만 저장한다. 닉네임에 개인정보 패턴이 있으면 거절한다. 응답에는 계정 ID·비밀번호 해시를 싣지 않는다. IP는 저장하지 않는다.
- **고지**: 글은 이용자 의견이라 `AI_NOTICE`가 아니라 `COMMUNITY_NOTICE`를 붙인다. 승패·유불리를 판정하는 기능은 만들지 않는다.
- **씨앗**: 로그인 사용자의 글 1개 10개, 댓글 1개 5개. 씨앗 1개 = 할인 1원 가치(글 100개 = 댓글 200개 = 1,000원). 하루에 씨앗을 받는 글 5개·댓글 10개, 너무 짧은 글은 제외, 지우면 회수.
- **씨앗 사용은 꺼져 있다**: 구독·유료 결제 할인은 과금이라 `billing` 게이트 승인 전까지 만들지 않는다(`SEEDS.redeemEnabled = false`). 켤 때는 유효기간·할인 한도·결제 연동을 PRD에서 먼저 정한다.

- **민감정보**: 건강·범죄경력처럼 민감한 내용으로 보이는 글·댓글은 `sensitiveConsent: true`가 있어야 받는다(없으면 `409 CONSENT_REQUIRED`). 화면은 올릴지 한 번 묻고, 동의한 시각·종류만 남긴다.
- **신고**: 같은 네트워크의 같은 글 신고는 하루 한 번만 센다. `REPORT_FOLD_AT`건이 쌓이면 제목·본문을 가리고, 관리자 모드가 신고 수를 되돌리거나 글을 지운다.

## 열어 둔 것

댓글 수정, 검색, 민감정보 동의 문구의 법무 검토, 로그인 사용자 삭제 요청에 커뮤니티 글을 포함할지.
