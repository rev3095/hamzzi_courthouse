# lib/procedure — 절차 안내 (F-014 데모 축소판, DEC-021)

결과 화면(S-04)의 절차 타임라인·첫 단계 추천. **LLM을 쓰지 않는 순수 규칙**이고 결과(승소·처벌)를 판정하지 않는다.

| 파일        | 역할                                                                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `steps.ts`  | 단계 상수(준비할 것·주의점·난이도 라벨·공식 링크·"이 단계 질문하기" 문장). 법률 검토 전이라 화면에 "참고용 · 법률 검토 전". 기간·비용 숫자 없음(OQ-DM-09) |
| `policy.ts` | `classifyCase`(질문 문장·법령 이름 → 유형), `procedurePlan`(타임라인 또는 유형 안내), `evidenceSummary`(근거 개수), `recommendText`                       |

- 민사 금전 청구(`money`)·주택 보증금(`lease_deposit`)만 타임라인을 그린다. 노동·형사·소장을 받은 쪽·판단 불가는 유형 안내와 공식 링크만.
- 첫 추천 단계는 지금 규칙상 언제나 내용증명이다. 바꾸려면 테스트(`policy.test.ts`)부터 고친다.
- 단계 문구에 숫자·단정 표현이 들어가면 테스트가 막는다 (절대 규칙 2·3).
- `procedure_guide` 게이트는 기간·비용이 붙는 정식 F-014(`GET /procedures`)용이다. 이 축소판에는 걸지 않는다.
