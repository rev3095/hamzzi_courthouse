# lib/procedure — 절차 안내 (F-014 데모 축소판, DEC-021)

결과 화면(S-04)의 절차 타임라인·첫 단계 추천. **LLM을 쓰지 않는 순수 규칙**이고 결과(승소·처벌)를 판정하지 않는다.

| 파일        | 역할                                                                                                                                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `steps.ts`  | 섹션별 타임라인 `TRACKS`(단계·준비할 것·주의점·난이도 라벨·공식 링크·"이 단계 질문하기" 문장, 먼저 추천할 단계). 법률 검토 전이라 화면에 "참고용 · 법률 검토 전". 기간·비용·인원 숫자 없음(OQ-DM-09) |
| `policy.ts` | `classifyCase`(질문 문장·법령 이름 → 타임라인), `procedurePlan`(타임라인 또는 유형 안내), `shortcutOf`('바로 가기' 대상), `evidenceSummary`(근거 개수), `recommendText`                              |

타임라인은 홈 예시 질문 섹션을 따른다 (DEC-021):

| 섹션      | 타임라인                                | 먼저 추천           | 예시                   |
| --------- | --------------------------------------- | ------------------- | ---------------------- |
| 임대차    | `lease_deposit` 보증금 반환             | 내용증명            | lease-01               |
| 임대차    | `lease_residence` 계속 거주·갱신 분쟁   | 대항력·사실 확인    | lease-02, lease-03     |
| 계약금    | `contract_deposit` 계약금·가계약금 반환 | 내용증명            | deposit-01, deposit-02 |
| 노동      | `wage` 임금·퇴직금 체불                 | 고용노동부 진정     | wage-02                |
| 노동      | `dismissal` 부당해고                    | 노동위원회 구제신청 | trap-number            |
| 사기      | `fraud` 거래 사기 피해                  | 고소·신고           | fraud-01               |
| 교통사고  | `traffic` 교통사고 손해배상             | 사고·진료 기록 정리 | other-01               |
| 이웃 분쟁 | `neighbor` 이웃 간 피해                 | 대화·요청           | trap-vague             |
| (그 밖)   | `money` 돈을 돌려받는 절차              | 내용증명            | 자유 질문              |

- 타임라인은 요구하는 쪽(피해자·임차인·근로자) 기준이다. 갚거나 돌려줘야 하는 쪽·서류를 받은 쪽(`defendant`), 고소·신고를 당했거나 사고를 낸 쪽(`accused`), 형사만(`criminal`), 판단 불가(`other`)는 타임라인을 숨기고 유형 안내와 공식 링크만.
- 분류에는 질문 문장과 찾은 법령 이름만 쓴다. 분석의 분야·목표 문장은 모델이 쓴 것이라 미리 검증한 예시 재생(`replay`)일 때만 함께 본다.
- '바로 가기' 카드는 내용증명(문서 안내, 게이트 뒤) 또는 단계에 정해 둔 `shortcut` 공식 창구로만 간다. 없으면 카드를 보이지 않는다.
- 분류 순서가 곧 우선순위다(수사 받는 쪽 → 서류 받은 쪽 → 갚을 쪽 → 해고(임금 청구가 함께면 임금) → 임금 → 교통사고 → 계약금 → 주택 보증금(전세사기 포함) → 사기(빌려준 돈 제외) → 이웃 → 주택 거주 → 금전). 바꾸면 `policy.test.ts`의 예시 10개 고정 테스트부터 고친다.
- 단계 문구에 숫자·단정·승패 표현이 들어가면 테스트가 막는다 (절대 규칙 2·3).
- `procedure_guide` 게이트는 기간·비용이 붙는 정식 F-014(`GET /procedures`)용이다. 이 축소판에는 걸지 않는다.

## 홈 카테고리 · 생활 분쟁 섹션 (DEC-026)

| 파일             | 역할                                                                                                                                                                            |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `categories.ts`  | 홈 카테고리 버튼 11개(이름·설명·안내·placeholder·문장 시작·기본 타임라인·고정 판례 검색어 `caseQuery`·판례 사건 종류·예시 id). 분류 기준은 생활법령정보 분야 (docs/research/06) |
| `life-tracks.ts` | 새 섹션 타임라인 `LIFE_TRACKS`: 가족·이혼(`family`)·상속(`inheritance`)·소비자·환불(`consumer`)·명예훼손·온라인(`defamation`). 공식 서식 작성기와 잇지 않는다(`document` 없음)  |

- `procedurePlan`은 새 섹션이면 `kind: "life_timeline"`을 낸다(기존 섹션은 `timeline`). 화면은 `hasTimeline(plan)`으로 둘 다 타임라인으로 그린다. 종류를 나눈 까닭: 문서 초안(lib/documents)이 기존 섹션 키(`TrackKey`)만 다루므로 그쪽 타입을 바꾸지 않기 위해서.
- `classifyCase(r, question, category?)`: 규칙이 먼저다. 카테고리는 규칙 결과가 `other`·`criminal`이면 그 카테고리 타임라인으로, `money`면 생활 분쟁 섹션을 골랐을 때만 바꾼다. `accused`·`defendant`는 바꾸지 않는다.
- 자유 질문 규칙 낱말: 이혼·양육비·재산분할 → `family`, 상속·유산·유류분·한정승인 → `inheritance`, 명예훼손·모욕·악플·허위사실 → `defamation`(셋은 해고·임금보다 먼저), 환불·청약철회·반품·쇼핑몰 → `consumer`(사기 다음).
- 테스트: `categories.test.ts`(분류·카테고리 보조), `policy.test.ts`(새 섹션·카테고리 문구도 숫자·단정·승패 표현 검사).
