# lib/mascot — 햄찌 판사 상태별 그림 (브랜드 가이드 2.3)

화면은 상황에 맞는 상태를 `HamzziJudge mood=…`로 넘기고, 그 상태 그림이 없으면 기본 그림(`public/mascot/hamzzi-judge.webp`)을 쓴다.

| 파일                  | 책임      |
| --------------------- | --------- |
| `moods.ts`            | 상태      | 그림                                                                  | 쓰는 곳 |
| ---                   | ---       | ---                                                                   |
| `default` 기본        | 기본 그림 | 홈 히어로                                                             |
| `thinking` 분석 중    | thinking  | 결과 화면 분석 진행 (104px, 잔잔히 움직임)                            |
| `error` 오류          | petite    | 결과 화면 오류(검색·모델 실패, 시간 초과, 일시적 오류) (96px)         |
| `sorry` 답변이 어려움 | petite    | 결과 없음, 하루 상한 (96px), 질문 3번 안내 (88px)                     |
| `ask` 재질문 필요     | curious   | 가린 문장 확인 필요 (96px)                                            |
| `done` 기쁨           | relieved  | 결과 화면 "햄찌 판사의 정리" 머리 아이콘 — 얼굴 `manifest.faces.done` |
| `curious` 궁금함      | curious   | 햄찌 안내 챗봇 첫 인사 (64px, 정지)                                   |
| `calm` 차분           | 기본 그림 | 그림만 준비. 움직이지 않는다                                          |

캐릭터는 결과를 가리지 않게 작게 둔다(브랜드 가이드 2.4). 얼굴(`faces`)은 전신 그림에서 잘라 따로 넣고, 편집기는 전신 그림만 바꾼다.

편집기: `pnpm studio`(이 컴퓨터에서만 받는 개발 서버) → `/studio`. 배포에서는 화면·API 모두 404다.

- `pnpm dev`는 같은 네트워크의 다른 기기 요청도 받는다. 브라우저 요청은 막지만 헤더를 꾸민 도구 요청까지 막지는 못하니, 그림을 바꿀 때는 `pnpm studio`를 쓴다.
- 저장한 그림과 `manifest.json` 변경은 `git status`에 보인다. 커밋 전에 내가 올린 그림인지 확인한다.
