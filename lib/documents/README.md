# lib/documents — 단계별 공식 서식 설문·편집·내보내기 (DEC-022·023·025·055)

DEC-055(2026-11-25)로 **게이트 없이 모두에게 열려 있다** — 햄찌법원이 무료로 대신 작성한다.

- `POST /api/v1/documents/{kind}`·`POST /api/v1/documents/{kind}/draft`는 게이트를 보지 않는다.
- 초안 도우미는 사실관계 문장(`screenFacts`) 뒤에 법적 근거·주장 문장(`screenLegal`, 법령·판례 언급 허용, 최대 4)을 이어 붙인다.
- 이름·주소·금액은 브라우저 밖으로 보내지 않는 규칙은 그대로다.

| 파일                               | 역할                                                                                                                                                                                                                                                                                                           |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fields.ts`                        | 서식 형식(Field·DocumentSpec)과 공통 칸 도우미(이름·주소·연락처·작성일·법원·이자)                                                                                                                                                                                                                              |
| `specs/*.ts`                       | 섹션별 서식 정의 (예: `specs/criminal.ts` 사기)                                                                                                                                                                                                                                                                |
| `fill-kit.ts` · `fill-*.ts`        | 채우기 공통 도구와 섹션별 채우기 (예: `fill-criminal.ts`)                                                                                                                                                                                                                                                      |
| `policy.ts`                        | 서식 정의를 담는다. 브라우저에서도 쓰므로 server-only를 넣지 않는다. 내용은 아래 목록 참고                                                                                                                                                                                                                     |
| `fill.ts`                          | `fillBlocks`: 입력값을 공식 서식 순서의 블록(title·heading·text·center·right·blank)으로 놓는다                                                                                                                                                                                                                 |
| `draft.ts`                         | 초안 도우미(DEC-023) 규칙: `ruleSuggestions`, `FACTS_FIELD`(사실관계 칸), `partyWords`, `screenFacts`·`screenMissing`, `factsText`                                                                                                                                                                             |
| `export/index.ts`                  | 형식 고르기 `buildFile`(형식별 코드는 dynamic import), `fetchFonts`, `downloadFile`                                                                                                                                                                                                                            |
| `export/docx.ts` · `export/zip.ts` | DOCX(WordprocessingML)와 무압축 ZIP. 의존성 없음                                                                                                                                                                                                                                                               |
| `export/hwpx.ts`                   | HWPX(OWPML). 의존성 없이 한글 표준 구조(`<hp:t>`, 첫 run 안 `secPr`, 첫 항목 무압축 mimetype)로 직접 만든다. hwpx-mcp-server로 글자·정렬을 읽어 확인했고, 한컴오피스 한글 2022에서 서식 14종이 열리고 글자가 같은 것·한글에서 고쳐 다시 저장되는 것을 확인했다(2026-11-18). 문단 안 줄바꿈은 `<hp:lineBreak/>` |
| `export/pdf.ts`                    | PDF. `pdf-lib`·`@pdf-lib/fontkit`(MIT)에 나눔고딕(SIL OFL, `public/fonts`, 서브셋)을 넣는다                                                                                                                                                                                                                    |

`policy.ts`에 들어 있는 것:

- `DOCUMENT_SPECS`: 칸·설문 페이지·쉬운 설명·예시·공식 서식 이름과 출처·근거 조문
- `invalidFields`: 페이지 단위 검사. 오류에는 칸 이름만 넣는다
- `parseDocumentInput`: 입력 검증
- `fillDocument`: 블록과 텍스트를 만든다

## 지키는 것

- **값을 지어내지 않는다.** 사용자가 적은 값을 정해진 칸과 법원 서식 기본 문장(신청취지·청구취지·신청이유)에 넣기만 한다. LLM을 쓰지 않고, 법률 판단·이자·비용을 셈하지 않는다. 지급명령 독촉절차비용 합계만 사용자가 적은 두 금액의 덧셈이다.
- **주민등록번호·생년월일·입금 계좌는 받지 않는다.** 문서에 빈칸으로 남기고 화면에서 직접 적으라고 안내한다(F-007).
- **1회용이다.** 입력과 편집 결과는 화면 메모리에만 있다. 쿠키·localStorage·서버에 저장하지 않는다. 파일(HWPX·DOCX·PDF)도 브라우저 안에서 만들어 바로 내려받는다. 이름·주소·금액은 서버·외부 API로 가지 않는다.
- **결과 표시를 단다.** AI 생성물이 아니어서 `DOCUMENT_NOTICE`를 쓴다. AI 문장이 들어가면 `AI_NOTICE` + `DRAFT_NOTICE`를 쓴다. 모든 서식에 `CHECK_NOTICE`(제출 전 법원 안내·전문가 확인)를 붙인다.
- **화면 흐름** (`components/documents/DocumentStudio.tsx`):
  1. 설문 팝업(`SurveyDialog`)에 답한다.
  2. 입력대로 곧바로 완성한다.
  3. "이대로 내보낼까요?"에 예 또는 아니요("직접 수정할게요")를 고른다.
  4. 아니요면 편집기(`DocumentPaper`)에서 고친다. 문단 고치기·추가·삭제·정렬을 할 수 있다.
  5. 저장한다. 메모리에서 확정만 하고 어디에도 쓰지 않는다.
  6. 다시 예 또는 아니요("계속 수정할게요")를 고른다.
- **초안 도우미 (DEC-023)**: 결과 화면이나 타임라인 단계의 '서식 작성하기'가 `?from=<질문 번호>`로 온다.
  - `POST /documents/{kind}/draft`는 질문 번호만 받는다.
  - 그 질문의 마스킹본으로 규칙 칸과 사실관계 칸 초안(`FACTS_FIELD`, Haiku 1회 $0.0015)을 돌려준다.
- **개발 검사 도구**: `.mcp.json`의 `hwpx`(hwpx-mcp-server, MIT)로 만든 HWPX 파일을 열어 볼 수 있다. 서비스 런타임에서는 쓰지 않는다.

## 여러 파일에 걸친 규칙 (CLAUDE.md에서 옮김, 2026-11-25)

- 문서 작성(lib/documents, DEC-022·025)은 DEC-055로 게이트 없이 모두에게 열려 있다(무료 AI 대리 작성). 사용자 입력을 칸에 넣기만 하고 저장·로그하지 않는다. AI 생성물이 아니라 `AI_NOTICE` 대신 `DOCUMENT_NOTICE`. 초안 도우미(DEC-023, `POST /documents/{kind}/draft`)는 질문 번호만 받아 마스킹본으로 규칙 칸 + Haiku 초안($0.0015) — 사실관계 문장 뒤에 법적 근거·주장 문장(`screenLegal`, 법령·판례 언급 허용, 최대 4)을 이어 붙여 청구원인 등을 대신 쓴다 — 을 주고, 그때는 `AI_NOTICE` + `DRAFT_NOTICE`. 이름·주소·금액은 브라우저 밖으로 보내지 않는다(양식 채우기는 브라우저에서, 저장소·쿠키 없음). 서식 14종(임대차·사기·노동·분쟁조정·집행, 목록은 lib/documents/README.md)은 공식 기관 서식·법령 기준이고(사설 양식 금지, docs/research/05), 화면은 설문 팝업 → 완성 → 예/아니요 → 웹 편집기 → 저장 → 예/아니요, 내보내기 HWPX(한글 표준 구조로 직접 작성)·DOCX(자체 ZIP)·PDF(pdf-lib + public/fonts 나눔고딕)는 모두 브라우저 안에서 만든다. 주민등록번호·생년월일·입금 계좌는 받지 않는다. 새 서식은 `specs/<섹션>.ts` + `fill-<섹션>.ts`에 더한다.
