# lib/guide — 햄찌 안내 챗봇 고정 문안 (DEC-030)

화면 어디서나 오른쪽 아래 햄찌 버튼으로 여는 안내 창(`components/guide/GuideBot.tsx`, `app/layout.tsx`)의 문안이다. 메뉴를 고르면 정해진 답을 보여 준다. **Claude 호출 없음 · 비용 0 · 입력 칸 없음 · 대화 저장·로그 없음.** 고지는 `GUIDE_NOTICE`("정해진 안내 · AI 생성 아님")다.

| 파일             | 책임                                                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `topics.ts`      | 메뉴 7개(사이트 규정·기능 안내·이용약관·요금제·변호사법·운영 방안·문의·개발자 연락처 — 변호사 연결 메뉴는 DEC-055로 폐기)와 하위 질문, 링크, 근거(`source`) |
| `policy.test.ts` | 단정·승률·위법 여부 표현, 숫자, 실제 페이지 링크, 하위 질문 참조, 이메일 위치 검사                                                                          |

## 문안을 바꿀 때

1. 근거 문서(`source`)를 먼저 확인한다 — `docs/PRD.md`(0절·6장·10장·16장 DEC/OQ), `docs/research/03_규제_쟁점.md`, `app/terms`·`app/privacy`·`app/sources`. 문서에 없는 내용은 쓰지 않는다.
2. 변호사법 항목은 "걸린다/안 걸린다"를 말하지 않고 지금 운영 방식(DEC-001·055: 돈을 받지 않음, 배정·수수료 없음 — 자문 변호사 정보는 싣지 않는다)과 살펴본 조항 이름만 쓴다. `docs/research/03`의 [추정] 위험도·결론은 옮기지 않는다.
3. 앞으로의 계획은 "계획"으로만 쓴다. DEC-055로 전면 무료라 요금·가격·유료화 계획을 쓰지 않는다. 변호사 연결(Phase 2)은 폐기했고, 문서 작성(무료 AI 대리 작성)은 열려 있다.
   운영 방식을 나열한 뒤에는 "이것만으로 법 위반 여부가 정해지지 않는다"를 함께 둔다(사실 나열이 결론처럼 읽히지 않게).
4. 숫자는 `GUIDE_LIMITS`에서만 가져온다. 테스트가 원래 상수(`ANON_QUESTION_LIMIT`·`EXAMPLE_RATE` 등)나 개인정보처리방침 문구(24시간·30일)와 대조한다. 고지 문구는 `AI_NOTICE`·`SEARCH_NOTICE`를 넣어 쓴다.
5. 변호사법 조문 번호는 분석 결과가 아닌 고정 인용(`docs/research/03` [확실])이고, 법제처 원문 링크(`/laws/변호사법`)를 함께 단다.
6. 개발자 이메일(사용자 요청)은 공개 저장소에 그대로 보인다. 화면에서는 '이메일 보기'를 눌러야 나타나고, 코드에는 조각으로 둔다.
