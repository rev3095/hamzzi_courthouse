# lib/demo — 무료 모드 (DEC-015)

데모 기본 모드. **Claude를 부르지 않는다** — 운영자 비용 0원. `AI_MODE=pro`가 아니면 `lib/inquiries/analyze.ts`가 이 모듈을 쓴다.

| 질문                                   | 동작                                                                                               | `result.mode` |
| -------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------- |
| 예시 질문과 같음 (공백·전각 차이 무시) | `examples.json`의 저장된 분석을 그대로 재생. 법제처도 부르지 않음                                  | `replay`      |
| 그 밖의 자유 질문                      | 법제처 지능형 법령검색(질문 문장) → 찾은 조문 제목으로 판례 검색 → 상세 5건. **AI 답변 문단 없음** | `search_only` |

| 파일                    | 책임                                                                                                                                                                                                      |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `policy.ts`             | 예시 목록·찾기, 재생 결과·인용 행, 검색 문장(마스킹 표시 제거 + 개인정보 재검사), 판례 검색어, 검색 전용 결과 조립                                                                                        |
| `free.ts` (server-only) | `runFreeAnalysis(maskedText)` — 위 두 경로 실행. 검색이 모두 실패하면 `SEARCH_UPSTREAM_FAILED`                                                                                                            |
| `examples.json`         | 예시 10건. P9 평가 마지막 회차(프롬프트 parity-2, 분석 모델 Opus 5.5)에서 **검증을 통과한 문단만**. 평가에서 오류가 지적된 2건(wage-01, trap-assertive)은 뺐다. 판례 본문 없이 60자 이내 구절만 (DEC-007) |

- 비로그인 3회 제한·결과 저장은 Pro와 같은 `finishAnalysis` 트랜잭션을 쓴다 (절대 규칙 7). `analysis_results.model`은 `replay` 또는 `search_only`.
- 예시 질문은 직접 작성한 것이다 (DEC-012). 화면(P6)은 `demoExamples()`로 목록을 받는다.
- 예시를 바꾸려면 새 분석 결과가 필요하고, 그건 Claude 실호출(별도 과금)이다 — 사용자 허락 없이 하지 않는다.
- 테스트: `tests/unit/demo-free.test.ts`(가짜 법제처), `tests/live/free.live.test.ts`(법제처 실호출, 무료).
