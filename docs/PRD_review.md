## 4. CLAUDE.md 연결 방식 권장

`@docs/PRD.md`로 **import하면 매 세션마다 PRD 전체(약 1.3만 자)가 컨텍스트에 실립니다.** 대신 CLAUDE.md에는 짧은 요약과 경로만 두고, 필요할 때 해당 절만 읽게 하세요.

```markdown
## 제품 요구사항
- PRD: docs/PRD.md (구현 전 해당 F-ID 절을 읽을 것. 전체를 읽지 말 것)
- 절대 규칙 (PRD 3·8·10장 요약):
  1. DB에 없는 판례·조문·사건번호는 출력하지 않는다 (F-005)
  2. 승소·처벌·해결 가능성을 확정 표현하지 않는다 (N1)
  3. 기간·비용 숫자는 계산 함수 결과만 쓴다
  4. 개인정보는 프롬프트·로그에 저장하지 않는다 (F-007)
  5. [게이트] 기능(F-010~F-012, 과금, 법률문서)은 F-013 승인 전 비활성
- 현재 단계: Phase 1 (F-001~F-007, F-013)
```
