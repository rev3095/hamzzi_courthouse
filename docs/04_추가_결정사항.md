# 04. 추가로 작성할 것 · 생각하고 결정해야 할 것

현재 기획 내용으로 PRD v0.1은 만들 수 있지만, 아래 항목이 정해져야 v1.0(개발 착수 가능 상태)이 됩니다.
**🔴 = 개발 전 반드시 결정 / 🟡 = Phase 진입 전 결정 / 🟢 = 진행하면서 결정**

## A. 법률·규제 (가장 먼저)

| ID | 결정 사항 | 왜 중요한가 | 선택지 / 할 일 |
|---|---|---|---|
| 🔴 D-01 | **변호사 마켓 수익 구조** | 변호사 소개·알선의 대가로 건별 수수료를 받는 구조는 변호사법상 금지되는 알선 대가로 볼 위험이 큽니다. 기존 변호사 플랫폼들도 이 문제로 직역 단체와 분쟁을 겪었습니다. | ① 변호사 월 정액 구독/광고형 ② 사용자 멤버십형 ③ 결제 대행 수수료(구조 자문 필요) → **리걸테크 경험 있는 변호사 자문 받기** |
| 🔴 D-02 | **유료 소장 작성·AI 첨삭의 범위** | 비변호사가 돈을 받고 소장 등 법률 문서를 작성해주면 법률사무 취급으로 볼 위험이 있습니다. | ① 사용자가 직접 쓰는 "서식 도구 + 정보 제공"으로 한정 ② 변호사/법무사 검토를 붙인 제휴형 ③ 무료 제공 + 다른 곳에서 수익 |
| 🔴 D-03 | **데이터 소스별 이용 조건** | "열람 가능한 선"의 기준이 소스마다 다릅니다(열람 가능 ≠ 수집·재배포 가능). | 소스 목록 확정 → 각 약관/robots.txt/API 조건 표 작성 → 불가 소스는 링크만 |
| 🔴 D-04 | 판결문 비식별 기준 | 공개 판결문도 재가공 시 추가 비식별이 필요할 수 있음 | 마스킹 규칙, 검수 프로세스 |
| 🟡 D-05 | 사업자 형태 | 변호사 법인 제휴 vs 일반 IT 법인 → 가능한 사업 범위가 달라짐 | 법인 설립 전 자문 |
| 🟡 D-06 | 이용약관·개인정보처리방침·면책 고지 | 출시 필수 | 변호사 검토본 |
| 🟡 D-07 | AI 기본법 대응 | 생성형 AI 고지 등 의무 | 고지 문구·표시 위치 |
| 🟡 D-08 | 변호사 평가·후기 정책 | 변호사 광고 관련 규정, 명예훼손 리스크 | 실제 이용자만 작성, 신고·검수 절차 |

## 변호사 자문 시 물어볼 질문 (초안)

1. 변호사에게 월 정액 광고/구독료를 받고 프로필을 노출하는 구조는 허용되나요? 상담 1건당 수수료는요?
2. 사용자가 입력한 정보로 소장 서식을 자동으로 채워주는 기능을 유료로 제공할 수 있나요? "AI 첨삭"은 어떤 범위까지 가능한가요?
3. AI가 유사 판례와 일반적인 절차·기간·비용 범위를 안내하는 것은 법률 상담에 해당하나요? 어떤 표현을 피해야 하나요?
4. 사용자 후기·별점·담당 사건 수를 공개하는 것에 제약이 있나요?
5. 공개 판결문을 재가공(요약·비식별)해 게시할 때 주의할 점은?
