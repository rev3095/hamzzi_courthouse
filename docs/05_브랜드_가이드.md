# 05. 햄찌법원 브랜드 가이드 v0.1

> 기준 시안: 디자인 캔버스의 **"D+ · 햄찌법원 — 화이트 마블 × 햄찌 판사"**

## 1. 브랜드 핵심

| 항목 | 내용 |
|---|---|
| 이름 | **햄찌법원** (영문 **Hamzzi Court**) |
| 한 줄 정의 | 누구나 무료로 판례를 찾고, 햄찌 판사와 함께 내 사건의 길을 한눈에 보는 법률 길잡이 |
| 슬로건(안) | "귀엽지만, 답은 진지하게." / "판례에서 찾고, 근거로 안내해요." |
| 브랜드 약속 | ① 근거(판례·조문) 없이 말하지 않는다 ② 결과를 단정하지 않는다 ③ 개인정보는 가린다 ④ 기본 열람은 무료 |
| 성격 키워드 | 친근함 · 성실함 · 투명함 · 차분함 |
| 피할 인상 | 장난스러움, 가벼움, 공공기관 사칭, 과장 광고 |

### 이름 표기 규칙
- 한글 표기 기본: **햄찌법원** (띄어 쓰지 않음)
- 영문: **Hamzzi Court** (로고 보조 표기, 이탤릭 세리프)
- ❌ 햄지법원 / 햄찌 법원 / HAMZZI COURT(전부 대문자는 로고 외 금지)

## 2. 마스코트 "햄찌 판사"

### 2.1 캐릭터 설정

| 항목 | 내용 |
|---|---|
| 종 | 골든 햄스터 (털색 기본 `#E9A94B`) |
| 복장 | 검은 법복(`#1A2233`) + 흰 깃(자보) + 금색 단추 |
| 소품 | 나무 판사 방망이(머리 `#6E4426`, 손잡이 `#8A5A32`, 금테 `#C9A24A`) + 받침 블록 |
| 머리 장식 | 올리브 월계관(`#6F8A4E`) — 그리스·보타니컬 콘셉트와 연결 |
| 무대 | 대리석 기둥 무늬 받침대 위에 서 있음 |
| 성격 | 성실하고 다정함. 기다리는 동안 열심히 판례 서고를 뒤짐. 조금 엉뚱하지만 근거 없는 말은 안 함 |
| 말버릇 | 친근한 "~요"체. 가끔 "탕탕!" 같은 의성어(로딩·이스터에그에서만) |
| 정체성 표기 | 항상 **"AI 캐릭터"** 로 표기. 실제 판사·법원이 아님 |

### 2.2 등장 위치

| 위치 | 크기 | 형태 | 동작 |
|---|---|---|---|
| 홈 히어로 | 200~240px | 전신 + 받침대 + 말풍선 | 클릭하면 방망이 두드림 |
| 로딩 | 40~52px | 얼굴 아바타 + 진행 문구 | 해바라기씨 점 애니메이션 |
| 결과 헤더 | 40~52px | 얼굴 아바타 + "햄찌 판사의 정리 · AI 캐릭터" | 정지 |
| 약속 블록 | 64px | 얼굴(월계관) | 정지 |
| 내비 로고 / 파비콘 | 32~44px | 얼굴(월계관) | 정지 |
| 푸터 | 28px | 단순화한 얼굴 | 정지 |
| 빈 상태 / 오류 | 120~160px | 전신, 상황별 표정 | 선택 |

### 2.3 표정 세트 (최종 일러스트 제작 시 필요)

| 표정 | 쓰는 곳 |
|---|---|
| 기본(미소) | 홈, 결과 |
| 집중(방망이 들고) | 로딩 |
| 기쁨 | 결과 완료, 저장 완료 |
| 고민 | 정보가 더 필요할 때(인테이크 추가 질문) |
| 미안 | 오류, 검색 결과 없음 |
| 차분(방망이 내려놓음, 월계관만) | 형사·가정폭력 등 민감한 사건 유형 |

### 2.4 해야 할 것 / 하지 말 것

| ✅ 한다 | ❌ 하지 않는다 |
|---|---|
| UI 안내(말풍선·로딩·빈 상태)에서 말한다 | 판례 요약·비용·절차 **본문**을 캐릭터 말투로 쓰지 않는다 |
| "정리해 드려요", "찾아볼게요" | "판결합니다", "이길 거예요", "유죄예요" |
| 결과 옆에 "AI 캐릭터" 표기 | 실제 법원 로고·대법원 상징·정의의 여신상과 함께 쓰기 |
| 민감 사건에서는 차분한 표정, 대사 최소화 | 피해·범죄 상황에서 농담·의성어 |
| 동작 줄이기 설정을 존중(`prefers-reduced-motion`) | 결과를 가리는 큰 애니메이션 |
| 털색은 골든 기본. 이벤트 때만 변형 | 캐릭터 비율·복장을 임의로 바꾸기 |

### 2.5 대사 예시

| 상황 | 대사 |
|---|---|
| 첫 방문 | "무슨 일이 있었나요? 편하게 말해 주세요!" |
| 로딩 | "판례 서고를 뒤지는 중이에요…" |
| 결과 완료 | "정리 끝! 아래에서 확인해 보세요." |
| 정보 부족 | "조금만 더 알려주시면 더 비슷한 판례를 찾을 수 있어요." |
| 결과 없음 | "비슷한 판례를 아직 못 찾았어요. 다르게 표현해 볼까요?" |
| 오류 | "앗, 서고 문이 잠깐 잠겼어요. 잠시 후 다시 시도해 주세요." |
| 캐릭터 클릭(이스터에그) | "정숙! … 은 농담이에요. 질문은 언제든 환영!" |
| 민감 사건 | (대사 없이 차분한 표정) + 본문에 상담 기관 안내 |

## 3. 디자인 토큰

### 3.1 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FAF9F6` | 페이지 바탕(화이트 마블) |
| `--white` | `#FFFFFF` | 카드·패널·입력창 |
| `--ink` | `#1A2233` | 본문 글자, 주요 버튼(질문 버튼), 법복 |
| `--muted` | `#5A6272` | 보조 글자 |
| `--gold` | `#A9873C` | 강조선, 아이콘, 타임라인 노드 |
| `--cream` | `#F4EEE1` | 태그·아이콘 바탕 |
| `--honey` | `#FFF4DE` | 마스코트 영역 바탕(약속 블록, 아바타) |
| `--line` | `#E6E2D8` | 테두리 |
| `--sage` | `#6F8A4E` | 월계관·식물 장식·체크 아이콘 |
| `--fur` | `#E9A94B` | 햄찌 털색(캐릭터 전용, UI 버튼에 쓰지 않음) |
| `--success-text` | `#3D5A40` | 판례 결과(인용 등) 글자 |

규칙
- 주요 버튼(CTA)은 `--ink` 하나만 씁니다. 골드는 선·아이콘용이고, 흰 글자를 올리는 버튼 바탕으로 쓰지 않습니다(대비 부족).
- 본문 글자 대비 4.5:1 이상. `--muted`보다 연한 회색을 본문에 쓰지 않습니다.
- 다크 모드는 v0.2에서 정의합니다(바탕 `#12161F` 계열, 골드 밝게 보정).

### 3.2 타이포그래피

| 용도 | 글꼴 | 굵기 | 크기(데스크톱 / 모바일) |
|---|---|---|---|
| 로고·히어로 제목 "햄찌법원" | Noto Serif KR | 900 | 104px / 56px |
| 영문 보조 "Hamzzi Court" | Playfair Display Italic | 600 | 28px / 20px |
| 섹션 제목 | Noto Serif KR | 700 | 46px / 30px |
| 카드 제목·결과 제목 | Noto Serif KR | 700 | 19~26px |
| 본문·UI | IBM Plex Sans KR | 400~700 | 16px(최소) / 질문창 18px |
| 캡션·고지 | IBM Plex Sans KR | 400 | 13px |

### 3.3 형태·간격

| 항목 | 값 |
|---|---|
| 모서리 | 패널 16px · 카드 12px · 버튼 8px · 칩 999px |
| 간격 단위 | 4px 배수 (자주 쓰는 값 8 / 14 / 20 / 32 / 80) |
| 최대 너비 | 본문 1120px · 질문창 820px |
| 터치 영역 | 최소 44×44px |
| 그림자 | 질문창·패널에만, 아주 옅게 (`0 18px 50px -28px rgba(26,34,51,.5)`) |
| 질문창 테두리 | 골드 그라데이션 5px 프레임 (`#EBDDB8 → #F8F2E3 → #E3D2A8`) |

### 3.4 장식 요소
- 대리석 결: 바탕에 아주 옅은 곡선(`#DDD7C9`, 투명도 60%)
- 올리브 가지: 히어로 양쪽 모서리에 선 드로잉만 사용(채우기 없음)
- 기둥 무늬: 마스코트 받침대에만 사용

### 3.5 아이콘
- 선(stroke) 아이콘, 두께 1.8~2.2px, 끝 둥글게
- 이모지는 UI에 쓰지 않습니다(⚖ 고지 기호만 예외)

### 3.6 모션

| 이름 | 쓰는 곳 | 길이 |
|---|---|---|
| knock (방망이 두드리기) | 로딩 중, 캐릭터 클릭 | 0.45s 반복 |
| wiggle (몸 흔들기) | 캐릭터 호버 | 0.6s 1회 |
| seeds (해바라기씨 튀기) | 로딩 표시 | 1s 반복 |

`prefers-reduced-motion: reduce`이면 모두 끕니다.

## 5. 구현 메모 (Claude Code 지시용)

```
docs/05_브랜드_가이드.md의 디자인 토큰을 tailwind.config.ts theme.extend에 옮겨줘.
- colors: bg, ink, muted, gold, cream, honey, line, sage, fur
- fontFamily: display(Noto Serif KR), accent(Playfair Display), sans(IBM Plex Sans KR)
- borderRadius: panel 16px, card 12px, button 8px
그리고 components/mascot/HamzziJudge.tsx를 만들어줘.
- props: size('hero'|'avatar'|'icon'), mood('default'|'focus'|'happy'|'think'|'sorry'|'calm'), knocking:boolean
- 시안의 SVG를 기준으로 하되 장식용이면 aria-hidden, 클릭 가능하면 button + aria-label
- prefers-reduced-motion일 때 애니메이션 끔
- 하드코딩 색상 금지, 토큰만 사용
```
