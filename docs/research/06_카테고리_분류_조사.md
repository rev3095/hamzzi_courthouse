# 06. 홈 카테고리 분류 조사 (DEC-026)

> 조사일 2026-11-18. 홈 카테고리 버튼과 새 절차 섹션을 정하기 위해 공식 분류 체계를 확인했다. 판례 건수는 법제처 판례 검색(판례명 기준, 무료 조회) 결과이며 시점에 따라 바뀐다.

## 1. 공식 분류 체계

| 출처 | 분류 | 쓰는 곳 |
|---|---|---|
| 법원 사건부호 예규(재일 2003-1 별표) — [정리](https://korea.legal/실무자료/법원-사건부호-사건별-부호문자의-부여에-관한-예규/), [법률신문 해설](https://www.lawtimes.co.kr/news/articleView.html?idxno=220209) | 사건번호 부호로 종류가 정해진다: 민사(가단·가합), 가사(드·느·므), 형사(고단·고합), 행정(구합), 특허(허·후) 등. 자음은 심급(ㄱ 1심·ㄴ 항소심·ㄷ 상고심), 모음은 유형 | 카테고리별 판례 범위 설명(`caseKinds`) |
| 법제처 판례 목록 API — [open.law.go.kr 안내](https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=precListGuide) | 응답에 `사건종류명`·`사건종류코드`(녹화본: 민사 = 400101). 요청 필터는 법원종류(`org`)·법원명(`curt`)·참조법령(`JO`)·사건번호(`nb`)·선고일 — **사건 종류 필터는 없다** | 검색은 검색어로만 좁힌다 |
| korean-law-mcp `search_precedents` | 검색어·검색 범위(판례명/본문)·법원·사건번호·선고일 | 같음 |
| 법제처 찾기쉬운 생활법령정보 — [분야](https://www.easylaw.go.kr/CSP/CnpClsMain.laf) | 대분류 18개(가정법률·부동산/임대차·금융/금전·소비자·민형사/소송·교통/운전·근로/노동·정보통신/기술·사회안전/범죄 등). 가정법률 아래 이혼·상속·양육비·유언 등 | **카테고리 버튼 기준** (국민 생활 기준 공식 분류) |
| 대한법률구조공단 상담 분야 (2차 자료) | 민사·가사·형사·행정 | 공식 상담 창구 링크 |

판례 자체의 분류는 민사·형사·가사·행정 수준이라 일반 사용자 버튼으로는 넓다. 그래서 버튼은 생활법령 분야, 판례 사건 종류는 설명용으로 나눠 쓴다.

## 3. 지킨 규칙
- 타임라인 문구: 기간·비용 숫자 없음(기간은 "정해진 기간이 있어요, 법원 안내에서 확인"), 단정·승패 표현 없음 — `lib/procedure/policy.test.ts`가 새 섹션·카테고리 문구까지 검사한다.
- 링크는 정부·법원·공공기관 https 주소만.
- 카테고리 검색어(`caseQuery`)는 정해 둔 법률 용어라 질문 문장이 섞이지 않는다 (F-007).
