# 리서치 1. 판결문·법령 데이터 공식 소스와 이용 조건

> 조사일: 2026-10-19 · 작성: Claude Code (웹 검색 기반)
> 표시: **✅ 확인** = 공식 페이지/조문에서 확인 · **🔶 보도** = 언론·2차 자료 기준 · **❓ 미확인** = 공개 자료로 확인 못 함 → 담당 기관에 문의 필요

## 요약

- **가장 안전한 1차 소스는 법제처 Open API입니다.** 공공데이터포털에 "판례 본문 조회" API가 **무료, 이용허락범위 제한 없음**으로 등록되어 있습니다(✅). 아카이브 MVP는 이 소스로 시작하세요.
- **대법원 판결서 인터넷 열람은 "사람이 1건씩 1,000원 내고 보는" 서비스입니다.** 자동 수집·재배포를 허용한다는 공식 근거를 찾지 못했습니다(❓). 그러니 크롤링하지 말고 **사건번호와 열람 링크만 제공**하세요.
- 법원 공개 범위 자체가 좁습니다. 형사 미확정 판결과 소액사건 판결문 등은 공개되지 않습니다(🔶). 그래서 AI가 "비슷한 소액사건 판례"를 찾는 데 한계가 있다는 점을 기획에 반영해야 합니다.

## 법적 배경 (데이터 활용 관점)

| 항목 | 내용 | 확인 수준 |
|---|---|---|
| 판결 자체의 저작권 | 저작권법 제7조: 법령·판결 등은 보호받지 못하는 저작물. 다만 **수집처 DB·사이트 약관은 별개**입니다 | ✅ (조문) |
| 데이터베이스 제작자 권리 | 상당한 투자로 만든 DB는 보호받을 수 있고, 무단 대량 수집은 분쟁 소지가 있습니다 | 🔶 |
| 크롤링 형사책임 판례 | 대법원 2021도1533(야놀자 vs 여기어때): 접근을 객관적으로 막는 조치가 없으면 정보통신망 침입 등은 무죄. **약관·기술적 차단이 있으면 결론이 달라질 수 있습니다** | 🔶 |
| 판결문 공개 정책 변화 | 1,000원 수수료와 형사 미확정 판결 비공개에 대한 헌법소원이 헌재 전원재판부에서 심리 중이라는 보도 있음 | 🔶 |
| 해외 분쟁 | 캐나다 CanLII가 AI 법률 리서치 업체를 데이터 대량 수집으로 제소. 미국 Fastcase vs Alexi 소송 | 🔶 |

## 햄찌법원에 주는 시사점

1. **MVP 아카이브 = 법제처 API만 사용.** 수집 로그와 출처(법제처, 수집일)를 화면에 표시하세요.
2. **법원 판결서는 "찾아가는 길"만 안내.** 사건번호 → 사법정보공개포털 열람 링크(사용자가 직접 1,000원 결제)로 연결합니다.
3. **AI 근거 판례 = 법제처 데이터에 있는 것만 인용.** 2026년 3월 법원행정처가 AI 허위 판례 인용에 소송비용을 물리는 방안을 발표했습니다(🔶). 없는 판례를 지어내면 사용자가 실제 손해를 볼 수 있으니, "DB에 없는 사건번호는 출력 금지"를 코드 수준 가드레일로 두세요.
4. **소액사건 판례 공백 대응.** 공개 판례가 부족한 유형(소액·형사 미확정)은 "공개 판례가 적은 유형"이라고 표시하고, 판례 대신 절차 안내 중심으로 보여주세요.
5. **기관에 직접 확인할 것**(❓ 항목)
   - 법제처: Open API 판례 데이터를 상업 서비스에서 재게시·요약·AI 학습에 써도 되는지, 출처 표시 방식, 호출 한도 (문의 02-2109-6446, open.law.go.kr 안내 기준)
   - 법원행정처: 판결서 인터넷 열람 자료의 자동 수집·재배포 가능 여부, 대량 이용 제휴 가능 여부
   - NIA: AI Hub 법률 데이터셋별 상업적 이용 조건
