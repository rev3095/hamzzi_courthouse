답변 문단:
1. **[제6조, 확인]** "다음 세입자를 구해야 반환" 조건이 계약서에 있는지부터 확인하라. 받은 근거에는 그 주장을 직접 다루는 조문이 없어 근거만으로는 답하기 어렵다고 밝힘.
2. **[제6조, 확인]** 갱신거절 통지가 없으면 같은 조건으로 다시 임대차한 것으로 보는 규정(묵시적 갱신)과 그 예외.
3. **[2024다326398, 확인]** 보증금을 받기 전에 이사하면 대항력이 문제될 수 있다 — 대항요건은 계속 갖춰야 한다는 판례, 임차권등기 전에 점유를 잃은 사례.

관찰:
- 좋았던 점: 근거로 답할 수 없는 부분을 "근거만으로는 답하기 어렵다"고 밝혔고, 이사하면 대항력을 잃을 수 있다는 핵심 위험을 판례로 짚었다.

- 아쉬운 점(모델 문제): 4번 문단은 질문 상황과 맞지 않는 조문(협력 등기)을 끌어왔다.

## 4. 2026-11-19 Opus 비교 절차

1. **코드 준비 (내일 모델 교체 때)** — 지금 `AI_ANSWER_MODEL` 허용 목록에는 Opus가 없다(생각을 끌 수 없어서). 넣으려면:
   - `lib/ai/models.ts` `ANSWER_MODELS`에 `claude-opus-5-5` 추가: 생각은 `adaptive`, effort `medium`(사용자 지정)
   - 라이트 경로가 effort를 `low`로 고정하고 출력 한도가 1,200토큰(`LITE_ANSWER_TOKENS`)이라, Opus는 생각 토큰까지 들어가도록 모델별 effort·출력 한도를 따로 둔다
   - 1건 상한(`liteCapUsd`)과 주간 건수: 상한을 올리면 주간 $80 안에서 건수가 줄어든다(예: 상한 $0.15면 주 533건)
   - 단가: Opus 5.5 입력 $4 · 출력 $20 / 1M 토큰 (Sonnet의 2배). `lib/ai/cost.ts` `PRICES`에 추가
2. **배포 후 실행 (1회, 유료)**: `node --env-file=<.env.local 경로> scripts/live-compare.mjs opus` → `evals/live-compare/2026-11-19_opus.json`
3. 이 문서 2절 표 오른쪽 칸과 5절을 채운다. **받은 근거 목록이 Sonnet 때와 같은지 먼저 비교한다** — 법제처 검색 결과가 하루 사이 바뀌면(새 판례 등) 모델 차이와 섞인다.

예상 비용 (추정, 실측 아님): 입력은 Sonnet과 비슷한 약 7천 토큰 → 약 $0.03, 출력은 생각 포함 1.5천~3천 토큰 → $0.03~0.06. **질문 1건 약 $0.06~0.09 (약 80~130원)**.

답변 문단 (모두 인용 구절이 원문과 일치):
1. **[제3조, 확인]** 이사할 때 대항력을 먼저 확인하라. 집을 넘겨받고 주민등록을 마치면 다음 날부터 제3자에게 임차권을 주장할 수 있고, 이 보호는 보증금을 받기 전까지 중요하다.
2. **[2024다326398, 확인]** 대항요건(점유·주민등록)은 계속 유지해야 한다는 판례. 이사한 뒤에야 임차권등기가 된 사안에서 임차권을 주장할 수 없다고 본 점을 들어, "등기가 마쳐졌는지 확인한 뒤 이사"하라고 순서를 짚음.
3. **[2026다201978, 확인]** 전세보증금반환보증 가입 여부는 사연에 없다고 먼저 밝힌 뒤, 가입했다면 집 인도와 보증공사의 이행이 동시이행 관계라는 판례를 안내.
4. **[민간임대주택 특별법 시행령 제5조, 확인]** 집주인이 등록 임대사업자인 경우의 규정. 조정·소송 절차가 있다는 점을 함께 안내.

## 6. 세 모델 비교 (같은 상황)

| 볼 것 | Haiku · Light (lease-01, 11-18) | Sonnet · Pro (이 문장, 11-18) | Opus · Pro Max (이 문장, 11-19) |
|---|---|---|---|
| 질문에 바로 답하는가 | 비껴감 (집주인이 바뀐 경우를 설명) | 방향은 맞음. "근거만으로는 답하기 어렵다"고 밝힘 | 이사 순서(등기 확인 → 이사)를 판례로 짚음. "새 세입자" 주장 자체는 다루지 못함 |
| 인용 정확성 | 지어낸 인용 0 | 4개 중 1개 구절 불일치, 맞지 않는 조문(협력 등기) 1개 | **4개 모두 일치**, 구절도 더 길고 정확 |
| 사연에 없는 사실 다루기 | — | — | "가입 여부는 사연에 나와 있지 않다"고 먼저 밝히고 가정으로 안내 |

| 비용 / 시간 | $0.0009 / 7초 | $0.021 / 12초 | $0.085 / 28초 |

판단 (질문 1건 기준, 채점 없음):
- **Opus가 확실히 나은 점**: 인용이 전부 원문과 맞았고, 사연에 없는 사실은 없다고 밝힌 뒤 가정으로 말했으며, 판례에서 "무엇을 먼저 해야 하는지"를 끌어냈습니다. 화면에 "확인 필요" 표시가 하나도 없습니다.
- **Opus도 못 고친 점**: 이 상황의 핵심 근거(임차권등기명령 제3조의3, 보증금 반환과 집 인도의 동시이행 일반론)가 이번에도 검색 결과에 없었습니다. 저장된 예시 lease-01(Opus 전체 파이프라인, 재검색 포함)은 똑같은 상황의 판례(2024다321973)를 찾아 5문단으로 답했는데, 이번 답변은 거기에 못 미칩니다. **차이를 만드는 것은 모델보다 검색(재검색)입니다.**
- **검색이 오히려 넓어진 부작용**: 새 검색어가 "보증금 반환"을 넓게 잡아 민간임대주택 특별법·한국주택금융공사법이 들어왔고, Opus는 그것을 조건부 문단으로 썼습니다. Sonnet 때는 주택임대차보호법만 들어왔습니다.
- **비용 대비**: Pro Max는 Pro의 약 4배 비용·2.5배 시간입니다. 인용 정확성과 신중함은 올라가지만, 핵심 근거가 없으면 답의 깊이는 크게 달라지지 않습니다. 기본 선택은 Pro로 두는 지금 설정이 맞다고 봅니다.

## 7. 측정 한계
