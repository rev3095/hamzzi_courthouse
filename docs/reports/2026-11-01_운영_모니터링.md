# 운영 점검·모니터링 (데모, 2026-11-01)

OQ-ARC-09(관측 도구 선택) 데모 제안. 비용 0원, 새 서비스 가입 없이 시작하고 필요할 때 도구를 붙인다.

## 1. 헬스 체크

`GET https://hamzzi-courthouse.vercel.app/api/v1/health` (인증 없음)

```json
{ "status": "ok", "checks": { "db": { "ok": true, "latencyMs": 40 }, "lawApi": { "ok": true, "latencyMs": 300, "cached": true } }, "version": "abcdef1", "time": "…" }
```

| 항목 | 뜻 |
|---|---|
| `status` | 둘 다 닿으면 `ok`(HTTP 200), 하나라도 실패하면 `degraded`(HTTP 503) |
| `checks.db` | Supabase에 3초 안에 조회되는지 (`feature_gates` 건수만) |
| `checks.lawApi` | 법제처 Open API에서 `민법 제1조`를 5초 안에 받는지. 인스턴스마다 5분 캐시(`cached`) |
| `version` | 배포 커밋 앞 7자리 (Vercel이 넣는 공개 값) |

비밀값·오류 문구·질문 내용은 내보내지 않는다. 실패 이유는 아래 로그에서 본다.

## 2. 무엇을 볼까

| 증상 | 어디서 | 확인할 것 |
|---|---|---|
| 사이트 전체 장애 | 헬스 체크 503 · Vercel Deployments | 마지막 배포가 실패했는지(빌드 로그), `checks.db`·`checks.lawApi` 중 무엇이 false인지 |
| DB 장애 (`checks.db` false, 질문·결과 API 500) | Supabase 대시보드 → Project | **무료 플랜 일시 정지**(7일 미사용) 여부 → Restore. 2026-11-01에 실제로 있었음 |
| 법제처 장애 (`checks.lawApi` false, 자유 질문·검색 502) | Vercel Logs에서 `errorCode: "SEARCH_UPSTREAM_FAILED"` | 법제처 점검·도메인 등록(open.law.go.kr)·`OPEN_LAW_API_KEY`. 예시 질문 재생은 법제처 없이 동작 |
| 오류 늘어남 | Vercel → Logs, 요청 로그 JSON | `status` 5xx, `errorCode`(표준 코드)·`errorType`(예외 이름)별 건수. 본문·메시지는 기록하지 않는다(F-007) |
| 느려짐 | 요청 로그 `latencyMs` | `/api/v1/inquiries/*/analyze#stream`(무료 모드 재생 ~2초, 검색 전용 ~5초), `/api/v1/cases`(목표 p95 3초) |
| 남용 | 요청 로그 `status: 429`, `errorCode: "RATE_LIMITED"` | 같은 시간대 급증이면 상한(DEC-010·017) 조정 검토 |
| 자동 파기 | Supabase SQL: `select * from cron.job_run_details where jobid = (select jobid from cron.job where jobname = 'hz-retention-purge') order by start_time desc limit 5;` | 매일 03:17 UTC 성공(`succeeded`) 여부. 감사 로그 `audit_logs.action = 'retention_purge'` |

요청 로그 한 줄 예: `{"requestId":"…","method":"GET","path":"/api/v1/cases","status":200,"latencyMs":812}` (lib/api/log.ts).

## 3. 알림 (제안, 사용자가 설정)

1. **외부 업타임 감시**: UptimeRobot·Better Stack 등 무료 요금제에 `/api/v1/health`를 5분 간격으로 등록하고, 200이 아니면 메일 알림. 5분 캐시 덕분에 법제처 호출은 인스턴스당 5분에 1번을 넘지 않는다.
2. **Vercel**: 프로젝트 Settings → Notifications에서 배포 실패 알림을 켠다. Hobby 플랜의 로그 보존 기간이 짧으므로 장애가 나면 바로 확인한다.
3. **Supabase**: 무료 플랜 일시 정지 메일을 받는 주소를 확인한다.
