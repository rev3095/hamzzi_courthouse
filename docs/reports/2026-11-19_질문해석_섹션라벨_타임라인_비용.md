# 질문 해석 · 절차 섹션 라벨 · 타임라인 확장 보고 (2026-11-19)

관련 결정: PRD DEC-033(질문 해석·섹션 라벨·타임라인 17개), DEC-034(홈 카테고리 28개·묶음 탭).
배포: `0bd4f62`(DEC-033, 2026-11-18), 홈 카테고리는 이 보고서와 같은 커밋.

## 1. 문제

- 직접 들은 욕설(오프라인)을 고소하려는 질문에 **온라인 명예훼손** 타임라인이 나왔다.
- 관련 없는 질문에 **노동법** 절차가 나오는 경우가 있었다.
- 같은 명예훼손이라도 온라인이 아니면 맞는 절차 타임라인이 없었다.

## 2. 원인 (변경 전 알고리즘)

라이트 답변(`AI_MODE=pro`)의 순서는 이랬다.

1. 법령 검색(AI 없음): 질문 문장 앞 200자를 그대로 법제처 지능형 법령검색에 넣어 조문 5개.
2. 판례 검색(AI 없음): 찾은 조문 제목 2개 + 홈 카테고리 고정 검색어.
3. Claude 호출 1회: 찾은 근거 안에서만 답변. 질문 해독·분야 판정·재검색 없음.
4. 인용 검증(AI 없음): 인용 구절과 원문 글자 대조 + 법제처 재조회.
5. 절차 타임라인(AI 없음): 질문 낱말과 1번에서 찾은 법령 이름으로 규칙이 섹션을 고름.

- 명예훼손·모욕 낱말이 있으면 무조건 "온라인 명예훼손·모욕 피해" 타임라인 하나로 갔다. 대면용 타임라인이 없었다.
- "찾은 법령에 근로기준법이 있으면 임금 절차" 같은 조건이 있어, 검색이 관련 없는 조문 하나를 섞어 오면 타임라인이 바뀌었다(교통사고·소비자도 같은 방식).
- 검색이 틀리면 답변과 타임라인이 함께 틀렸다. Claude는 주어진 근거 안에서만 답하므로 검색을 바로잡지 못했다.

타임라인은 미리 써 둔 13개 섹션에만 있었다. 그 밖의 질문도 검색과 답변은 됐지만 타임라인은 "정하지 못했어요"가 정상이었다.

## 3. 해결 (지금 알고리즘)

1. **질문 해석 (새로 추가, Haiku 1회)**: 검색 전에 섹션 라벨 + 법령 검색 문장 + 판례 검색어(2개까지)를 뽑는다.
   - 라벨은 고정 목록(`lib/procedure/sections.ts`)에서만 고른다. 목록 밖 값은 버린다.
   - 검색어는 개인정보·조문·사건번호·숫자·단정 표현 검사를 통과한 것만 쓴다. 바꿔 쓴 문장은 결과에 저장하지 않는다.
   - 실패하면(상한·시간 초과·형식 오류) 예전 방식으로 계속한다. 재시도는 없다.
2. 법령·판례 검색: 해석한 검색어로 찾는다.
3. Claude 답변 1회: 그대로.
4. 인용 검증: 그대로(AI 없음).
5. 절차 타임라인: **라벨로 섹션을 고르고**, 단계 문구는 전부 고정 문안이다. 라벨이 없으면(무료 모드·예시 재생·해석 실패) 낱말 규칙으로 정한다.

규칙도 고쳤다(무료 모드에도 적용).

- 명예훼손·모욕: 온라인 낱말이 있으면 온라인 타임라인, 없으면 직접 들은 말 타임라인.
- 법령 이름만으로 섹션을 정하지 않는다. 질문 문장이 있으면 그 분야 낱말이 함께 있을 때만 쓴다.
- 요구를 받는 쪽(수사를 받는 쪽·서류를 받은 쪽·갚을 쪽)으로 본 질문에는 요구하는 쪽 타임라인을 보이지 않는다.

### 추가한 타임라인 17개

| 묶음 | 타임라인 |
|---|---|
| 범죄 피해 | 직접 들은 욕설·모욕, 범죄 피해 고소(일반), 폭행·상해, 스토킹·협박, 성범죄, 보이스피싱 |
| 가족·학교 | 가정폭력, 학교폭력 |
| 일터 | 직장 내 괴롭힘, 산재 |
| 생활 | 의료사고, 개인정보 유출·도용, 상가 임대차, 채무조정 |
| 받는 쪽·행정 | 소장·지급명령을 받았을 때, 고소·신고를 당했을 때, 행정처분 불복 |

"형사만"·"수사를 받는 쪽"·"서류를 받은 쪽"에 나오던 범위 밖 안내는 타임라인으로 바뀌었다. 서류 없이 갚을 쪽인 경우만 범위 밖 안내로 남는다.

홈 카테고리 버튼도 11개에서 28개로 늘리고, 묶음 탭 6개로 나눠 보인다(DEC-034).

## 4. 확인한 것

- 무료 검사: 단위 테스트(가짜 모델), 린트, 타입 검사, 문서 검사, `pnpm build` 통과.
- 규칙 검토(legal-reviewer): 차단 1건·권고 9건을 모두 반영했다. 차단은 모델이 쓴 검색 문장이 검사 없이 화면·DB로 나가던 경로였다.
- **배포 사이트 실제 질문 1건**(사용자 승인, 2026-11-19):
  - 질문: "사람들 많은 식당에서 옆 테이블 사람이 저한테 입에 담기 힘든 말을 큰 소리로 퍼부었어요. 법적으로 대응하고 싶은데 어떻게 해야 하나요?" — '욕설'·'모욕' 낱말이 없어 예전 규칙으로는 섹션을 못 정하는 문장.
  - 라벨: `insult`(직접 들은 욕설·모욕). 대면 타임라인이 나온다.
  - 검색: 판례 검색어 "모욕 공연성", "모욕죄 욕설 공연히". 조문은 형법 제311조·제307조를 찾았고 노동법은 섞이지 않았다. 관련이 약한 조문 3개(국기 모독 2개, 군형법 초병 모욕)도 같이 나왔지만 답변에는 쓰이지 않았다.
  - 답변: 문단 4개. 3개는 인용 구절이 원문과 일치, 1개(제307조)는 구절이 원문과 달라 구절 없이 표시.
  - 응답 시간 약 15초. 이 1건의 실제 청구액은 확인하지 않았다(상한 $0.03).

## 5. 비용

답변 1건 금액은 2건 실측값(2026-11-18), 나머지는 단가표와 출력 한도로 계산한 **추정**이다.

| 구성 | 질문 1건 (Sonnet 답변) | 질문 1건 (Haiku 답변) |
|---|---|---|
| 이전: 답변 1회만 | 약 $0.020 (실측) | 약 $0.0009 (실측) |
| 지금: 질문 해석 + 답변 | 약 $0.0204 (추정) | 약 $0.0013 (추정) |
| 전부 AI로 | 약 $0.12~0.17 (추정) | 약 $0.006~0.009 (추정) |

- 질문 해석은 Haiku로 입력 약 2,800토큰·출력 약 120토큰, 약 $0.0003~0.0004다. Sonnet 기준 약 2% 증가다.
- 질문 해석은 답변과 같은 질문 1건 상한 안에서 쓴다. 질문 1건 상한(Sonnet $0.03 · Haiku $0.0015)과 주간 상한($80)은 그대로다.
- "전부 AI로"에서 늘어나는 몫(Sonnet 기준 추정): AI 재검색 $0.05~0.10, AI 인용 검증 약 $0.023, AI 타임라인 생성 약 $0.02~0.03.
- 주간 $80로 답할 수 있는 건수(실비 기준 추정): 지금 약 3,900건, 전부 AI면 약 500~650건.

**권장**: 인용 검증과 타임라인은 AI로 바꾸지 않는다. 인용 검증은 글자 대조가 AI보다 정확하고 무료다. 타임라인을 AI가 쓰면 기간·비용 숫자와 단정 표현이 섞일 수 있다(절대 규칙 2·3). 돈을 더 쓸 가치가 있는 곳은 검색(이번 질문 해석)과 답변 모델이다.

## 6. 한계 · 남은 일

- 새 타임라인 17개의 문구는 **법률 검토 전** 참고용이다. 화면에 "참고용 · 법률 검토 전"이 붙는다.
- 라벨 정확도는 실제 질문 1건만 확인했다. 여러 유형으로 재려면 유료 호출이 필요하다(절대 규칙 8: 승인 후 1회).
- 관련이 약한 조문이 섞이는 문제는 줄었지만 없어지지 않았다.
- 전체 파이프라인(`pro-full`)은 라벨을 내지 않아 규칙으로 정한다.
- 홈 카테고리 묶음 탭은 Figma에 아직 프레임이 없다(docs/07).
- 새 카테고리에는 예시 답변이 없다.
