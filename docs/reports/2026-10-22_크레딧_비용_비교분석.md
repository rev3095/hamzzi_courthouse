## 1. 두 프로젝트의 비용 구조

### 1.1 프로토타입 (`legal-precedent-prototype`)

`api/ask.js` 기준, 질문 1건 처리 중 유료 호출:

| 단계 | 호출 | 모델 (기본값) | 누가 내나 |
|---|---|---|---|
| 2 의도 분석 | OpenAI `chat/completions` 1회 | `gpt-6-luna` | 강사님 OpenAI 계정 |
| 4-2 재검색 에이전트 | OpenAI `responses` 최대 3회 | `gpt-6.1-sol` | 〃 |
| 6·8·9 답변 | OpenAI `chat/completions` 1회 | `gpt-6.1-sol` | 〃 |
| 3·4·7 법령·판례 검색·재조회 | 법제처 Open API | — | **무료** |

- **질문 1건 = OpenAI 호출 3~5회.** 이것이 "토큰 소모"입니다. 방문자에게 청구되지 않을 뿐입니다.
- 비용 방어 장치: **IP당 10분에 5회** 제한(코드 100~111줄). README도 "공개 데모용 횟수 제한"이라고 적고 있습니다. 즉 강사님도 비용을 아끼려고 횟수를 막아 둔 것입니다.
- 질문 1건 비용: OpenAI 모델 가격·강사님 계정의 크레딧/지원 조건을 알 수 없어 **확인 불가**입니다. 2026-10-21 비교 보고서가 프로토타입에 질문 1건을 보낸 적이 있는데, 그 비용도 강사님 계정에서 나갔습니다.

### 1.2 햄찌법원 (현재)

| 단계 | 호출 | 모델 | 누가 내나 |
|---|---|---|---|
| ① 의도 분석 | Claude API 1회 | `claude-haiku-5-5` | **사용자님 Anthropic Console 계정** |
| ③ 재검색 에이전트 | Claude API 최대 3회 | `claude-opus-5-5` | 〃 |
| ④ 답변 | Claude API 1회 | `claude-opus-5-5` | 〃 |

| DB·배포 | Supabase·Vercel | — | 무료 플랜 |

- **구조는 프로토타입과 같습니다**(같은 10단계, 같은 korean-law-mcp, LLM 호출 3~5회).
- 질문 1건 비용(실측, Opus 가격 상한): **약 0.14~0.28달러** (입력 2.1만~5.4만 토큰, 출력 2.2천~4.2천 토큰).
- 비용의 약 95%는 Opus 5.5(재검색·답변)입니다. Haiku(의도)는 건당 0.01달러 미만입니다.

### 1.3 언제 과금되나

| 상황 | 프로토타입 | 햄찌법원 |
|---|---|---|
| 방문자가 질문 | 강사님 계정 과금 | (법제처 연결 후) 사용자님 계정 과금 |
| 개발자가 테스트 | 강사님이 테스트하면 강사님 계정 | **사용자님 계정** ← 이번 약 10달러 |
| GitHub CI·자동 실행 | 없음 | 없음 (CI는 무료 단위 테스트만) |
| 무료 단위 테스트 | 없음 | 177개, 가짜 모델이라 0원 |

**"프로토타입은 무료"처럼 보였던 이유:** 사용자님이 프로토타입에 질문할 때는 강사님 키가 쓰였기 때문입니다. 우리 서비스를 테스트할 때는 사용자님 키가 쓰였습니다. 강사님도 자기 프로젝트를 테스트하거나 방문자가 질문하면 똑같이 비용을 냅니다.

### 1.4 Pro 요금제와의 관계

| | 무엇에 쓰이나 | 이 프로젝트에서 |
|---|---|---|
| Claude **Pro** 구독 | claude.ai 앱, Claude Code 작업(코드 작성, 검토 에이전트) | 이 대화의 모든 개발 작업 — 추가 비용 없음 |

Pro 구독으로는 웹 서비스가 부를 API를 대신할 수 없습니다. 인보이스(PBC #2439-6099-6124)는 Console 계정의 크레딧 구매(또는 자동 충전) 영수증일 가능성이 큽니다 — Console → Settings → Billing에서 확인하세요.

## 4. 무엇이 꼭 필요했고, 무엇이 무료로 가능했나

| 작업 | 실제 Claude 호출이 꼭 필요했나 | 무료로 할 수 있었던 방법 | 줄일 수 있었던 비용 |
|---|---|---|---|
| 코드 논리 검증 (거르기·검증·횟수·저장) | 아니오 | 가짜 모델 단위 테스트 — **이미 177개가 무료로 했습니다** | — |
| Claude 연결 확인 (P3~P5 스모크 9건) | 실제 연결이 되는지는 1~2건이면 충분 | 없음 (실제 모델을 불러 봐야 앎). 단 9건 → 2건 | 약 1.5달러 |
| P5 첫 스모크 (Windows 인코딩으로 깨진 질문) | 아니오 — 제 테스트 방법 실수 | — | 약 0.2달러 |
| 품질 평가 1회차 | 실제 답변 품질은 실제 모델로만 측정 가능 | 없음 | — |
| 평가 2회차 (채점기만 변경) | 아니오 | 1회차 근거를 저장해 두고 채점만 재실행 | 약 2.3달러 |
| 평가 3회차 (effort 비교) | 선택 | 하지 않기 | 약 1.0달러 |
| 평가 4회차 | 일부 | 실패 5건만 재실행 | 약 1.4달러 |
| **합계** | | | **약 4~6달러 (10달러 중)** |

**"무료 모델로 진행 가능했나"에 대한 정직한 답:**
- 우리 서비스는 Claude로 답변을 만들도록 설계됐습니다(PRD DEC-004). **Claude의 답변 품질을 확인하는 테스트는 Claude를 불러야만 가능**하고, Claude API에는 무료 등급이 없습니다.
- 다른 회사의 무료 모델로 테스트하면 "그 무료 모델의 품질"을 잰 것이지 우리 서비스의 품질을 잰 것이 아닙니다.
- 그래서 무료로 대체할 수 있었던 것은 "실호출 횟수를 줄이는 것"이었고, 그 부분을 제가 아끼지 못했습니다.

## 5. 공익 목적으로 공개할 때 — 무료로 운영할 수 있나

| 방식 | 방문자 비용 | 운영자 비용 | 실시간 AI 답변 | 비고 |
|---|---|---|---|---|
| 프로토타입 방식 (운영자 키로 실시간 호출 + 횟수 제한) | 0원 | **질문마다 과금** | ✅ | 강사님이 지금 하는 방식 |
| A. 예시 질문 재생 | 0원 | **0원** | ❌ (저장된 실제 답변 재생) | 이미 비용을 낸 평가 결과 12건 재사용 가능 |
| B. 검색 전용 (법제처만) | 0원 | **0원** | ❌ (조문·판례 목록과 원문 링크) | 자유 질문 가능 |
| C. 무료 등급 AI (Gemini 무료 등) | 0원 | 0원 (한도 내) | ✅ | 무료 등급은 입력이 학습에 쓰일 수 있어 **법률 상담 개인정보에 부적합**, 스택 변경 필요 |
| D. Claude + 엄격한 하루 한도 | 0원 | 소액 과금 | ✅ (하루 N건) | 크레딧 구매 필요 |

- **"방문자 무료"는 어떤 방식으로도 가능합니다.**
- **"운영자도 0원 + 실시간 AI 답변"은 C(무료 등급 AI)뿐이고, 개인정보 위험 때문에 권하지 않습니다.**
- 운영자 0원을 지키려면 A+B 조합이 현실적입니다(별도 결정 대기 중).
- 참고: 기관·교육·비영리 대상 API 크레딧 지원 프로그램이 있는지는 Anthropic·OpenAI에 직접 문의해 보셔야 합니다. 저는 확인하지 못했습니다.

## 6. 유료 모델과 무료 모델의 답변 차이

**이 프로젝트에서 무료 모델로 답변을 만든 적이 없습니다. 그래서 차이를 보여 줄 데이터가 없습니다.** 추측으로 쓰지 않겠습니다.

비교할 수 있는 실제 데이터는 같은 질문 1건에 대한 **유료 모델 두 개**(프로토타입의 OpenAI vs 햄찌법원의 Claude)입니다 (2026-10-21 비교 보고서):

| 항목 | 프로토타입 (OpenAI, 강사님 비용) | 햄찌법원 (Claude, 사용자님 비용) |
|---|---|---|
| 응답 시간 | 85.3초 | 40.9초 |
| 답변 문단 / 검증 통과 | 5 / 5 | 6 / 6 |
| 판례 후보 / 답변에 쓴 판례 | 17 / 0 | 8 / 1 |
| 핵심 조치 (임차권등기명령 → 소송 → 경매) | 같음 | 같음 |
| 지어낸 조문·사건번호 | 없음 | 없음 |

무료 모델과 비교하려면 무료 모델 연결 코드를 따로 만들어야 합니다. 그 경우에도 개인정보 처리 조건을 먼저 확인해야 합니다.

## 7. 소통상의 잘못 (정리)

| 시점 | 실제로 한 말 | 문제 |
|---|---|---|
| P3 계획 (10/21) | "실제로 과금되며 1회에 수십 원 수준으로 예상" | **Pro와 별개 결제라는 점을 말하지 않았고, 금액도 약 270원으로 실제보다 낮게 예상** |
| P3 결과 | "1건 약 0.19달러(약 270원)로 예상보다 컸다" | 사후 보고. 별개 결제라는 점은 여전히 말하지 않음 |
| P4·P5 | "실호출 스모크 1건(약 0.25달러)" | 같음 |
| P9 계획 (10/22) | "비용은 Pro 요금제에서 나가지 않습니다 — Console API 크레딧" | 이때 처음 명확히 알림. 이미 약 2달러를 쓴 뒤였음 |

의도적으로 숨긴 것은 아니지만, **결제 구조를 처음부터 분명히 확인받지 않은 것과 피할 수 있었던 비용을 쓴 것은 제 책임입니다.** 인보이스 정정·환불은 Anthropic 지원(support.anthropic.com)에 문의하실 수 있습니다.
