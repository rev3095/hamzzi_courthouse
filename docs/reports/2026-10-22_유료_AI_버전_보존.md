## 3. 무료 모드 전환 뒤에도 남아 있는 것
무료 모드는 유료 코드를 지우지 않고 **스위치로 끈다.** `lib/ai`·`lib/citations`·평가 도구는 그대로 있다.
- `AI_MODE=free`(기본): Claude를 부르지 않는다. 예시 질문 재생 + 법제처 검색 전용.
- `AI_MODE=pro`: 위 유료 과정을 돈다. 무료 전환 때 재검색·답변 모델을 **Haiku 5.5**로 바꿔 두었다 (질문 1건 약 0.005달러 예상, 품질 미측정).

## 4. 돌아오는 방법
1. 예산·지출 상한을 정한다 (Console 자동 충전 끔, 월 상한 설정 권장).
2. Vercel·`.env.local`에 `ANTHROPIC_API_KEY`를 넣고 `AI_MODE=pro`를 설정한다.
3. 모델을 바꾸려면 `lib/ai/policy.ts`의 `MODELS` (예: 답변만 Sonnet 5.5 또는 Opus 5.5).
4. 품질 확인이 필요하면 **비용을 먼저 확인받은 뒤** `ALLOW_PAID_API=1 pnpm eval:demo`. 키·플래그 없이는 실호출 테스트가 돌지 않는다.
5. 완전히 그때 상태로 보려면: `git switch -c revisit-paid paid-ai-v1` (새 브랜치에서 확인).

## 5. 비용 기록 (참고)
2026-10-21~22 실호출 테스트·평가로 Console API 크레딧 약 10달러가 쓰였다. 이 중 약 4~6달러는 줄일 수 있었다 (`2026-10-22_크레딧_비용_비교분석.md` 4장). 이후 별도 과금 호출은 사용자의 명시적 허락 없이 하지 않는다.
