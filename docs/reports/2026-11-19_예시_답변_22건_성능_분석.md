## 3. 성능 분석

### 3.1 모델(Opus 5.5 · medium)이 잘한 것
- **인용 정확성**: 남은 77문단 모두 인용 구절이 원문과 일치했습니다(구절 불일치 0). 11-18 Sonnet 실답변은 4문단 중 1문단이 구절 불일치였습니다.
- **근거가 부족할 때 밝힘**: 빌려준 돈 예시처럼 맞는 조문이 없으면 "직접 정한 조문이 없다"고 먼저 말하고, 판례의 사실관계가 질문과 다르다는 점도 적었습니다.
- **분량이 일정함**: 22건 중 20건이 3~4문단, 문단 합계 글자 수 중앙값 약 520자. 출력 토큰은 1,411~2,247로 출력 한도(5,000)의 절반 이하였습니다.

### 3.2 품질을 가른 것은 검색이었다
- 19건이 좋았던 이유도, 2건이 약했던 이유도 **받은 근거**였습니다. 분야 이름이 곧 법률 이름인 주제(스토킹, 학교폭력, 가정폭력, 개인회생, 산재)는 조문이 정확히 들어와 답이 좋았습니다.
- 일상 낱말로 묻는 민사 주제(빌려준 돈, 폭행 치료비)는 법령 검색이 엉뚱한 조문을 가져왔습니다. 11-18·11-19 비교 보고서의 결론("모델보다 검색")과 같습니다.
- 이전 예시 10건(2026-10-22, Opus 전체 파이프라인: 재검색 포함)은 4~6문단에 근거 조문 5~17개·판례 4~12건이었고 1건 $0.14~0.19였습니다. 이번 Pro Max는 재검색이 없어 3~4문단·근거 조문 5개·판례 5건, 1건 $0.075입니다. **비용은 절반 이하, 깊이는 한 단계 얕습니다.**

### 3.3 검증이 걸러 낸 것
- 86문단 중 9문단(10.5%)이 검증에서 빠졌습니다: 보이스피싱 4, 폭행·상해 2, 상속·지급명령·성범죄 각 1.
- 보이스피싱 4문단은 근거가 맞는데도 빠진 것으로 보여, 검증 쪽 오탐일 가능성이 있습니다(2절). 나머지 5문단은 빠진 이유를 확인하지 못했습니다(빠진 문단 내용은 저장하지 않음, DEC-014).

### 3.4 비용 구조
- 1건 평균 입력 약 9,700토큰 · 출력 약 1,800토큰. 입력이 비용의 약 절반입니다(입력 $0.039 + 출력 $0.036, Opus 단가 기준 평균).
- 주간 예산은 실제 쓴 금액이 아니라 상한($0.15 = 100단위)으로 차감합니다. 그래서 Pro Max만 쓰면 주 533건에서 막히고, 그때 실제 지출은 실측 평균($0.075) 기준 약 $40입니다.
- 예시 답변은 저장된 결과를 그대로 보여 주므로 방문자가 아무리 눌러도 추가 비용이 0입니다.

## 4. 다음에 할 만한 것 (제안, 미실행)

1. **보이스피싱 검증 오탐 확인 (무료)**: 통신사기피해환급법 조문을 인용 재조회 함수에 직접 넣어 실존 확인이 되는지 봅니다. 법제처 조회라 비용이 없고, 실제 사용자 답변에도 영향이 있어 우선순위가 높습니다.
2. **빠진 3개 카테고리 예시**: 1번을 고친 뒤 보이스피싱을 다시 만들고(1건 약 $0.08), 빌려준 돈·폭행·상해는 검색어를 손본 뒤 다시 만듭니다. 지금 다시 부르는 것은 권하지 않습니다.
3. **민사 일상 주제 검색 보강**: 카테고리마다 고정 법령 이름(대여금 → 민법, 폭행·상해 → 형법)을 검색에 더하는 방법. 법제처 조회만 늘어 Claude 비용은 그대로입니다.
