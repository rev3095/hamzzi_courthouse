## 1. 한 줄 요약 & 비전

**한 줄 요약**: 흩어진 판결문·법령·법률 자료를 한곳에 모아 누구나 무료로 찾아볼 수 있게 하고, AI가 내 상황에 맞는 판례·예상 기간·비용·절차를 한눈에 보여준 뒤, 변호사 연결 또는 혼자 진행(소장 작성)까지 이어주는 법률 길잡이.

**비전**: 법률 정보의 비대칭을 줄이고, 의뢰인과 변호사의 관계를 "일방적 갑을"에서 **투명한 정보 위의 수평적 거래**로 바꾼다.

**제품의 3층 구조**
1. **아카이브(공익·무료)** — 그 자체로 완결된 제품. 사용자가 앱을 지우지 않을 이유.
2. **AI 상담 길잡이(무료/일부 유료)** — 구조화된 질문 → 판례·기간·비용·절차 시각화.
3. **실행 단계(유료)** — ① 변호사 마켓 연결 ② 혼자 진행: 소장 자동 작성 + AI 첨삭.

## 2. 문제 정의

### 2.1 페인 포인트

| # | 문제 | 설명 |
|---|---|---|
| P1 | 법률 정보 허브 부재 | 판례·사례를 공개적으로 열람하고 한눈에 볼 수 있는 아카이브가 부족하다. 자료가 여러 사이트에 흩어져 있고 일반인이 찾기 어렵다. |
| P2 | 정보 비대칭 | 내 사건이 얼마나 걸리고, 얼마가 들고, 어떤 절차를 밟는지 변호사에게 묻기 전엔 알 수 없다. |
| P3 | 높은 상담 진입 비용 | 로펌·개인 변호사마다 일일이 상담을 신청해야 하고, 시간당 수십만 원에서 많게는 백만 원 선의 상담료가 든다. |
| P4 | 사건 진행의 연속성 부족 | 소송은 보통 수개월~1년 이상 걸리는데, 그 사이 담당 변호사가 바뀌거나 인수인계 공백이 생긴다. 수임료가 큰 사건을 우선 처리하면서 기존 사건이 다른 변호사에게 넘어가기도 한다. (기획자가 2년 전 직접 겪은 사례) |
| P5 | 폐쇄적인 가격·평가 구조 | 사건 담당 수, 실제 평가, 건당 가격, 전화·서면 상담 단가를 상담원/변호사에게 직접 물어봐야만 알 수 있다. 변호사 측이 절대적인 '갑'이 된다. |

### 2.2 가설
- 변호사(특히 로펌 소속이 아닌 개인 변호사)는 프리랜서·에이전시에 가까운 성격이 있어, **투명한 프로필·가격·평가 기반 마켓**에 참여할 동기가 있다. *(검증 필요: 변호사 인터뷰)*
- 사용자는 무료 아카이브와 AI 길잡이로 가치를 먼저 경험하면 유료 단계(변호사 연결/소장 작성)로 자연스럽게 이동한다.

## 3. 목표 / 비목표

### 목표
- G1. 공개 가능한 판결문·법령·해석례를 하나의 검색창으로 찾을 수 있다.
- G2. 법률 지식이 없는 사람도 질문 하나로 "관련 판례 · 예상 기간 · 예상 비용 · 절차"를 5분 안에 파악한다.
- G3. 사용자가 변호사 연결 또는 셀프 진행 중 하나를 근거를 가지고 고를 수 있다.
- G4. 변호사 정보(가격·평가·전문분야·담당 사건 수)를 투명하게 공개한다.

### 비목표 (하지 않는 것)
- NG1. **개별 사건의 승소 확률(%)이나 판결 결과를 단정하지 않는다.**
- NG2. 변호사를 대신해 법률 자문을 하거나 소송을 대리하지 않는다.
- NG3. 열람이 허용되지 않은 자료(유료 DB, 로그인/결제 뒤 자료, 크롤링 금지 소스)는 수집하지 않는다.
- NG4. MVP에서는 형사 변호·가사(이혼·양육) 셀프 소장 작성을 지원하지 않는다(리스크·복잡도가 높음).

**설계 기준**: 2~30대의 **가성비·가심비** 소비 성향에 맞추되, 4~50대도 설명 없이 바로 쓸 수 있을 만큼 UI/UX를 단순하게.

**수용 기준 (예시)**
- Given 사용자가 "퇴직금 미지급"을 검색, When 결과 페이지가 열리면, Then 관련 판례가 사건번호·법원·선고일·3줄 요약과 함께 2초 이내에 10건 이상 표시된다.
- Given 판결문 상세 페이지, Then 원문 출처 링크와 "개인정보는 비식별 처리되었습니다" 안내가 항상 보인다.
- Given 사건번호 형식(예: `2023가단12345`)을 입력하면, Then 해당 판결문으로 바로 이동한다.

### 7.2 AI 법률 길잡이 (상담 과정 AI화) (Phase 1)

**흐름**
```
① 홈 중앙 질문창에 자유 입력 → 돋보기(전송) 클릭
② AI가 사건 유형 판별 (예: 임금체불 / 전세보증금 / 대여금 / 손해배상 / 명예훼손·모욕)
③ 사건 유형별 Skill(인테이크 양식)로 부족한 정보만 짧게 추가 질문 (선택지 위주, 3~7문항)
④ 결과 화면: 관련 판례 · 예상 기간 · 예상 비용 · 법적 절차 직선 타임라인
⑤ 다음 단계 선택: [변호사와 진행] / [혼자 진행하기]
```

| ID | 기능 | 우선순위 |
|---|---|---|
| F-AI-01 | 중앙 질문창(자연어 입력, 돋보기 버튼 = 전송, Enter 전송, 예시 질문 칩) | P0 |
| F-AI-02 | 사건 유형 자동 분류 + 사용자가 수정 가능 | P0 |
| F-AI-03 | **인테이크 Skill**: 사건 유형별 정의된 양식(필수/선택 항목, 질문 문구, 선택지, 검증 규칙)으로 정보 수집 | P0 |
| F-AI-04 | 관련 판례 Top 3~5 카드(사건 요지, 결과, 내 상황과의 공통점/차이점, 원문 링크) | P0 |
| F-AI-05 | 예상 기간: 단계별 범위(최소~보통~최대)와 근거 | P0 |
| F-AI-06 | 예상 비용: 인지대·송달료(계산식 기반), 변호사 보수 범위(마켓 데이터 기반, 데이터 부족 시 "정보 부족" 표시) | P0 |
| F-AI-07 | **법적 절차 직선 타임라인**: 가로 한 줄에 단계(예: 증거 확보 → 내용증명 → 지급명령/조정 → 소송 → 판결 → 강제집행)와 각 단계 기간, 현재 위치 표시 | P0 |
| F-AI-08 | 준비 서류/증거 체크리스트 | P1 |
| F-AI-09 | 결과 저장·공유(링크), PDF로 내보내기 | P1 |
| F-AI-10 | "이 답변이 도움이 되었나요?" 피드백 | P0 |
| F-AI-11 | 무료 공공 기관 안내(대한법률구조공단, 노동청 등 상황별) | P1 |

**인테이크 Skill 정의 예시 (임금체불)**
```yaml
id: wage_arrears
title: 임금·퇴직금 체불
required:
  - employment_period: {q: "언제부터 언제까지 일하셨나요?", type: date_range}
  - unpaid_amount:    {q: "받지 못한 금액은 대략 얼마인가요?", type: money}
  - unpaid_type:      {q: "어떤 돈인가요?", type: multi, options: [월급, 퇴직금, 수당, 기타]}
  - employer_type:    {q: "회사 규모는?", type: single, options: [5인 미만, 5인 이상, 모름]}
optional:
  - evidence:         {q: "가지고 있는 자료", type: multi, options: [근로계약서, 급여명세서, 통장내역, 카톡/문자, 없음]}
procedure_template: wage_arrears_v1   # 진정 → 체불확인서 → 지급명령/소액소송 → 강제집행
```

**수용 기준 (예시)**
- Given 사용자가 "회사에서 두 달치 월급을 안 줘요"를 입력, When 전송, Then 3초 안에 '임금체불' 유형이 제안되고 인테이크 첫 질문이 나타난다.
- Given 인테이크 완료, Then 결과 화면에 판례 3건 이상, 기간 범위, 비용 범위, 타임라인 5단계 이상이 표시되고 **모든 판례 카드에 원문 링크**가 있다.
- Given AI 응답에 판례 근거가 없는 문장이 있으면, Then 해당 문장은 "일반 정보" 라벨로 구분된다.
- 결과 화면 하단에 항상 "본 정보는 법률 자문이 아닙니다" 고지가 표시된다.

## 8. AI 요구사항

### 8.1 AI가 하는 일 / 하지 않는 일

| 한다 | 하지 않는다 |
|---|---|
| 사건 유형 분류, 부족한 정보 질문 | 승소 확률·판결 결과 단정 |
| 관련 판례·조문 검색 및 쉬운 말 요약 | 출처 없는 법률 판단 |
| 계산 함수 결과를 설명 | 비용·기간 숫자를 스스로 지어내기 |
| 소장 초안의 빈칸·형식 점검 | "이렇게 하면 이깁니다" 식 전략 조언 |

### 8.2 구성
- **모델**: 메인 추론·요약 `claude-opus-5-5`, 분류·추출 등 대량 경량 작업 `claude-haiku-5-5` (평가 결과에 따라 조정)
- **RAG**: 하이브리드 검색(키워드 + 벡터) → 재정렬 → 상위 판례 문단을 근거로 요약, Citations로 문단 단위 인용
- **Tools**: `search_cases`, `get_case`, `get_statute`, `calc_court_fee`, `estimate_duration`, `build_timeline`, `estimate_lawyer_fee`
- **인테이크 Skill**: 사건 유형별 스키마(YAML/JSON) — 구조화 출력으로 검증

### 8.3 출력 규칙
1. 판례 인용 시 사건번호·법원·선고일 필수
2. 비용·기간은 계산 tool 결과만 사용, 범위로 표시 + "실제와 다를 수 있음"
3. 금지 표현: "반드시 이깁니다", "100%", "확실히" 등 결과 단정
4. 불확실하면 "추가 정보 필요" 또는 "변호사 상담 권장"으로 안내
5. 생성형 AI 결과임을 화면에 표시
6. **햄찌 판사 말투 규칙**: 말풍선·로딩·안내 문구 같은 UI 문구만 캐릭터 말투(친근한 "~요"체)로 씁니다. 판례 요약·기간·비용·절차 설명 본문은 중립적인 "~요/~니다"체로 쓰고 말장난·의성어를 넣지 않습니다.
7. 캐릭터는 결과를 "판결"하지 않습니다. "판결합니다", "유죄/무죄", "승소" 같은 표현을 캐릭터 대사로 쓰지 않습니다.

### 8.4 평가(Eval) & 출시 게이트

| 지표 | 정의 | MVP 출시 기준(안) |
|---|---|---|
| 출처 포함률 | 사실 주장 문장 중 citation 있는 비율 | ≥ 95% |
| 판례 관련성 | 평가셋 정답 판례가 Top 5에 포함 | ≥ 70% |
| 단정 표현 | 금지 표현 발생 건수 | 0 |
| 분류 정확도 | 사건 유형 분류 정답률 | ≥ 90% |
| 응답 시간 | 첫 토큰 / 전체 결과 | ≤ 2초 / ≤ 15초 |

평가셋: 사건 유형별 20건 × 5유형 = 100건으로 시작, 변호사(자문) 검수.

## 12. UX 원칙 & 핵심 화면

**UX 원칙**
1. **첫 화면 = 질문창 하나** (LexDiff 레퍼런스). 설명 없이도 "여기에 물어보면 된다".
2. 법률 용어는 쉬운 말 먼저, 전문 용어는 괄호/툴팁.
3. 숫자는 범위로, 근거는 한 번 클릭 거리에.
4. 4~50대 기준: 본문 16~18px, 큰 터치 영역, 단계형 진행.
5. 결과 화면은 위에서 아래로: 요약 → 판례 → 기간·비용 → 타임라인 → 다음 행동.

**디자인 콘셉트**: "아테네 법정에 들어서는 듯한" 그리스풍 + 보타니컬(올리브·월계수·대리석). 5종 시안 중 **D · 화이트 마블**(LexDiff 레이아웃 충실형)을 선택했고, 여기에 햄찌 판사를 더한 **"D+ 햄찌법원"** 시안으로 발전시키는 중.

### 12.1 마스코트 "햄찌 판사"

| 항목 | 내용 |
|---|---|
| 정체 | 판사 방망이(gavel)를 든 골든 햄스터. 검은 법복에 흰 깃, 머리에는 올리브 월계관 |
| 역할 | 서비스의 얼굴이자 안내자. 사용자를 맞이하고, 기다리는 시간을 덜 지루하게 하고, 다음 행동을 안내 |
| 성격 | 성실하고 다정함. 조금 엉뚱하지만 근거 없는 말은 하지 않음 |
| 하지 않는 일 | 판결·승패 예측·법률 자문. 캐릭터는 "정리해 주는 친구"이지 "판단하는 사람"이 아님 |

**화면별 등장 규칙**

| ID | 위치 | 동작 | 우선순위 |
|---|---|---|---|
| F-BR-01 | 홈 히어로 | 대리석 받침대 위에 서서 말풍선으로 맞이. 클릭하면 방망이를 두드림 | P0 |
| F-BR-02 | 질문 전송 직후(로딩) | 방망이를 두드리는 애니메이션 + "판례 서고를 뒤지는 중" 진행 단계 표시 | P0 |
| F-BR-03 | AI 결과 헤더 | 작은 얼굴 아바타 + "햄찌 판사의 정리" 라벨 + 인용한 판례 수 | P0 |
| F-BR-04 | 신뢰 약속 블록 | "햄찌 판사의 약속" 3가지(출처 표시 / 결과 단정 안 함 / 개인정보 가림) | P0 |
| F-BR-05 | 빈 상태·오류 | 검색 결과 없음, 오류, 점검 중 화면에 상황별 표정 | P1 |
| F-BR-06 | 내비·파비콘·푸터 | 얼굴 아이콘 | P0 |
| F-BR-07 | 접근성 | 애니메이션은 `prefers-reduced-motion`에서 끔. 장식용 일러스트는 스크린리더에서 숨기고, 캐릭터 버튼에는 대체 텍스트 제공 | P0 |

**수용 기준 (예시)**
- Given 사용자가 질문을 전송, When 결과를 기다리는 동안, Then 햄찌 판사 애니메이션과 진행 단계 문구가 보이고 결과가 나오면 멈춘다.
- Given 결과 화면, Then 캐릭터 아바타 근처에 "AI 캐릭터" 표기가 항상 있다.
- Given 동작 줄이기 설정 사용자, Then 캐릭터 애니메이션이 재생되지 않는다.

**핵심 화면 목록**
- S1 홈(질문창, 예시 질문 칩, 빠른 진입: 판례 검색 / 절차 알아보기 / 변호사 찾기)
- S2 인테이크(대화형 + 선택지)
- S3 AI 결과(판례 카드, 기간·비용, 절차 타임라인, 다음 단계 분기)
- S4 판결문 상세
- S5 소장 작성 위저드
- S6 변호사 목록/프로필/비교
- S7 마이페이지(저장한 결과, 진행 중 사건)

증거 정리 ─ 내용증명 ─ 지급명령 신청 ─ (이의 시) 소액소송 ─ 판결 ─ 강제집행
 1~2주       1~2주       약 1~2개월        수개월               필요 시
