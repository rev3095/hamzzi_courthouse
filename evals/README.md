# evals — AI 평가셋 (PRD 8.4)

사건 유형별 질의 + 전문가 검수 정답. 출시 기준: 허위 인용 0건, 출처 연결률 ≥95%, Top-5 ≥70%, 요약 정확도 ≥90%, 확정 표현·PII 노출 0건.

## 데모 평가 (P9, `pnpm eval:demo`)

- 질문 12건(`evals/demo/cases.json`: MVP 분야 8 · 교통사고 1 · 함정 3). 실제 경로(`runDemoAnalysis` → `verifyDraft`)를 돌리고 DB 저장·횟수 차감은 하지 않는다.
- 자동 채점(`grade.ts`): 허위 인용(최종 인용을 법제처에 다시 조회) · 단정 표현 · 원문에 없는 숫자 · 개인정보 · 출처 연결률 · 문단 제거율 · 핵심 내용 포함 · 시간 · 비용(Opus 가격 상한).
- AI 채점(`judge.ts`, Haiku 5.5): 질문에 답함 · 근거 원문과 맞음 · 사실을 지어내지 않음 · 결과를 단정하지 않음 · 다음 할 일을 알려 줌.
- 과금된다. `EVAL_BUDGET_USD`(기본 4.5)를 넘으면 새 질문을 시작하지 않는다. 결과는 `evals/results/<실행ID>/`(git 제외).
